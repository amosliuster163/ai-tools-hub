CC Switch 是什么？

CC Switch 是一个开源桌面工具，让你在 Claude Code、Codex、OpenCode 等 AI 编程工具中一键切换不同的模型提供商。

🎯 一键切换

点击界面按钮即可切换模型提供商

🔌 多提供商支持

百炼、MiniMax、DeepSeek 等

💻 跨平台

Windows / macOS / Linux

📦 支持多种CLI

Claude Code、Codex、OpenCode、Gemini CLI

安装方法

# 访问 https://github.com/farion1231/cc-switch/releases/latest
# 下载 CC-Switch-版本号-Windows.msi

# 方法2：Portable便携版
# 下载 zip 包，解压后直接运行 cc-switch.exe

macOS 安装

# 使用 Homebrew 安装
brew tap farion1231/ccswitch
brew install --cask cc-switch

Linux 安装

访问 GitHub Releases 下载对应Linux发行版的安装包

快速上手

  1. 启动 CC Switch（Windows在开始菜单，macOS在应用程序）
  2. 添加提供商：点击右上角 + 按钮，填写API Key和Endpoint
  3. 切换模型：点击提供商的「启用」按钮
  4. 重启 Claude Code：关闭所有Claude Code窗口，打开新终端
  5. 验证：在Claude Code中输入 /status 确认配置

使用场景

  • 多账号管理：有多个API Key，需要快速切换
  • 成本优化：便宜模型做日常任务，贵模型做复杂任务
  • 测试对比：同一提示词在不同模型上的表现对比
  • 故障切换：某个提供商挂了，快速切换到备用

常见问题

Q: 切换后Claude Code还是旧模型？

A: 环境变量在终端启动时加载，切换后需要关闭所有Claude Code窗口，打开全新终端。

Q: 提示环境变量冲突？

A: 检查并清理系统中的 ANTHROPIC_API_KEY、ANTHROPIC_BASE_URL 等环境变量，它们会覆盖CC Switch的设置。

Q: API 报 401 错误？

A: 检查API Key是否正确，Endpoint地址是否以 /anthropic 结尾（不是 /v1）。
