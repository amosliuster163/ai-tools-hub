> **核心概念**：确认偏误 (Confirmation Bias)
> **一句话**：你不是在寻找真相，你只是在证明自己没错。
> **完成时间**：约5分钟

张明是个坚定的"早起党"。

每天早上6点起床，跑步、冥想、吃健康早餐。他坚信早起是成功人士的标配。

有一天，朋友推荐了一篇文章：《研究表明，早起的人和夜猫子在生产力上没有显著差异》。

张明打开扫了两眼，心里就想："这研究样本量肯定不够，方法有问题。"

他继续搜索"早起的科学依据"，找到10篇支持早起的文章，心满意足地关了手机。

**他没有做的是**：认真看看那篇反对早起的文章到底说了什么。

## 什么是确认偏误？

确认偏误是人类最常见的认知偏差之一：**我们倾向于寻找、记住、和相信那些能证实我们已有观点的信息，而忽略或质疑相反的证据。**

简单说：**先有结论，再找证据。**

## 它是怎么运作的？

| 步骤 | 你的大脑在做什么 |
|------|------------------|
| 1. 形成信念 | "早起=成功" |
| 2. 主动搜索 | 搜索"早起的科学好处" |
| 3. 选择性接受 | 支持的文章 → "这很靠谱" |
| 4. 选择性拒绝 | 反对的文章 → "方法有问题" |
| 5. 信念加强 | "看吧，我说的没错" |

## 为什么大脑要这样？

因为**承认自己错了很痛苦**。

心理学有个概念叫"认知失调"——当事实和信念冲突时，人会感到不舒服。消除这种不舒服最快的方法不是改信念，而是否定事实。

## 真实案例

**投资中的确认偏误**：
- 你买了A股票 → 只看A的利好消息 → 忽略风险信号 → 亏了钱才恍然大悟

**职场中的确认偏误**：
- 你觉得同事B不靠谱 → 注意他每次迟到 → 忽略他按时交付的项目 → 关系越来越差

**AI时代的确认偏误**：
- 算法推荐你喜欢的内容 → 你看到的都是"同意你"的声音 → 你以为全世界都这么想

## 今日练习：反向搜索

**步骤**（5分钟）：

1. 想一个你坚信不疑的观点（比如"XX是最好的XX"）
2. 打开搜索引擎，输入："XX 的缺点" 或 "为什么 XX 不好"
3. 认真阅读前3条反对观点
4. 问自己：这些反对意见有没有道理？
5. 如果有，在纸上写下来

**完成标准**：
- [ ] 找到了至少1条反对观点
- [ ] 认真读完（不是扫一眼就关）
- [ ] 写下了自己的反思
