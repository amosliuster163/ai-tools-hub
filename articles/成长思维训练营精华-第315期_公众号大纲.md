> **核心概念**：地图不是疆域 (The Map is Not the Territory)
> **一句话**：你以为你在看世界，其实你在看地图。
> **完成时间**：约5分钟

[#📖](https://wx.zsxq.com/tags/%F0%9F%93%96/15442551812522) 故事开场

老周，公司战略总监

他有一个习惯：做决策前必看数据报表。

市场变化太快，数据总是滞后。按报表做的决策，次次踩空。

顾问说了一句话：你的报表是地图，市场是疆域。地图再精确，也不是真实的地形。

他不是不聪明，他是被困在了自己的思维模式里。

[#🧠](https://wx.zsxq.com/tags/%F0%9F%A7%A0/48554882124848) 思维模型

##核心逻辑

所有模型都是对现实的简化，必然遗漏重要信息。当你把模型当现实本身，就会犯错。

##经典案例

| 地图 | 疆域 |
|------|------|
| KPI考核表 | 员工真实贡献 |
| 用户画像 | 活生生的人 |
| 财务报表 | 公司真实健康状况 |
| SWOT分析 | 复杂的市场环境 |

##适用场景
- 看数据做决策时
- 用模型评估人时
- 战略规划时
- 任何你觉得事情就是这样的时刻

##反常识洞察
- 模型越精确，不代表越接近真相
- 好地图的价值在于有用，不在于真实
- 真正的高手，知道地图哪里不完整
