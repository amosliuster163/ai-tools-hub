安装

# 1. 下载并解压项目
unzip tie-tu-hao-automation.zip
cd tie-tu-hao-automation

# 2. 安装依赖
pip3 install -r requirements.txt

第一步：申请API Key

选项1：百炼（推荐，性价比高）

  1. 访问 阿里云百炼平台
  2. 用阿里云账号登录（没有就注册一个）
  3. 进入"API-KEY管理"页面
  4. 点击"创建新的API-KEY"
  5. 复制生成的Key（格式：`sk-xxxxxxxx`）

免费额度：新用户有免费额度，用完后按量计费（很便宜）

选项2：DeepSeek

  1. 访问 DeepSeek开放平台
  2. 注册并登录，创建API Key

选项3：MiniMax

  1. 访问 MiniMax开放平台
  2. 注册并登录，创建API Key

第二步：配置API Key

编辑 config.yaml 文件：

api:
  provider: "bailian"  # 改成你用的平台
  keys:
    bailian:
      api_key: "sk-你的百炼API密钥"  # ← 替换成你申请的Key
      base_url: "https://dashscope.aliyuncs.com/compatible-mode/v1"
      model: "qwen3.6-plus"

只需要改两个地方：

  • provider 改成你用的平台
  • 对应的 api_key 填进去

使用

# AI自动选题生成
python3 main.py --start 41 --end 50 --theme "认知偏误"

# 跳过AI，用本地JSON
python3 main.py --start 41 --end 50 --json cards.json
