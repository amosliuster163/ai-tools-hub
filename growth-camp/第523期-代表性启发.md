## 🔥 今日思维模型：代表性启发（Representativeness Heuristic）

**一句话解释**：人们喜欢根据"像不像典型"来做判断，而忽略真实的统计概率。看到一个人穿格子衬衫+背包，就觉得他是程序员——哪怕他可能是设计师。

---

## 💡 真实案例

你为什么觉得这个AI项目"一定能赚钱"？

> 这个项目创始人是名校毕业+有大厂背景+PPT做得很漂亮
> 你判断"像成功的项目" → 但统计数据表明90%的创业公司会失败
> 
> **你被"代表性特征"骗了，忽略了"基础概率"。**

**代表性启发的本质：大脑喜欢"讲故事"，而不是"算概率"。看起来像的事，不一定是真的。**

**在AI创业中：**

- 一个AI工具"看起来很酷" → 你觉得能赚钱 → 但用户不愿意付费
- 一个课程"包装很专业" → 你觉得质量好 → 但内容可能很水
- 一个竞品"数据很漂亮" → 你觉得很成功 → 但可能靠烧钱换来的

**记住：像不等于真。判断一件事，要看数据，不是看"像不像"。**

## 🤖 AI实战应用

### 1. 用AI做"基础概率分析"

```
我想评估XXX项目/投资/机会
请帮我：
1. 这个领域的基础成功率是多少？（不是个案）
2. 我是不是被某个"代表性特征"影响了判断？
3. 抛开"看起来怎么样"，真实概率是多少？
```

### 2. 用AI做"直觉vs数据对比"

```
我对XXX有一个直觉判断：[描述]
请帮我：
1. 这个直觉基于什么特征？
2. 这些特征和真实结果的相关性有多大？
3. 有没有数据可以验证或推翻我的直觉？
4. 帮我做一个"直觉vs数据"的对比分析
```

### 3. 用AI做"反代表性思考"

```
我觉得XXX"一定能行"（因为看起来很像成功案例）
请帮我：
1. 找出3个"看起来像但最终失败"的类似案例
2. 哪些关键因素我可能忽略了？
3. 给我一个"泼冷水"的客观分析
```
