## 🔥 今日思维模型：破窗效应（Broken Windows Theory）

**一句话解释**：一扇破窗如果不修，很快会有更多窗户被打破。

---

## 💡 真实案例

1969年，斯坦福心理学家津巴多做了个实验：

> 一辆好车停在贫民区→一周后没事
> 他把车窗砸了一个洞→几小时后车被偷了

**职场里的破窗效应：**

- 代码里一个小bug没修→团队开始写烂代码→项目质量雪崩
- 一次拖延没被纠正→团队习惯性拖延→项目延期成常态
- 一次内容敷衍没被批评→开始降低标准→账号质量越来越差

**个人成长里的破窗：**

- 今天没写日记→明天也没写→一个月没写→习惯彻底放弃
- 一次没运动→两次没运动→"算了，我就是不爱运动的人"

## 🤖 AI实战应用

### 1. 用AI做"窗户巡检员"

让AI每天检查你的"窗户"状态：

```
请帮我做今日巡检，检查这几个"窗户"：
- 写作习惯：今天写了吗？
- 运动习惯：今天动了吗？
- 学习计划：今天学了吗？
- 项目进度：今天推进了吗？

如果有"破窗"，请提醒我并帮我制定修复计划
```

### 2. 用AI做"即时修复工具"

发现破窗立刻修：

```
我今天的写作计划没完成（破窗了）
请帮我：
1. 分析为什么没完成（真实原因）
2. 制定一个15分钟的"紧急修复"方案
3. 帮我写一段开头，让我立刻开始
```

### 3. 用AI建立"防破窗机制"

```
请帮我设计一套"防破窗系统"，包括：
1. 每天必须守住的3个"窗户"（核心习惯）
2. 每个窗户的"最低标准"（比如每天写100字）
3. 如果破了窗，24小时内的修复流程
4. 每周日让AI做一次窗户状态评估
```
