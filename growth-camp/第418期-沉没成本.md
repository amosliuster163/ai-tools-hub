## 💡 今日模型：沉没成本（Sunk Cost Fallacy）

**定义**：人们在做决策时，会被已经投入的、无法回收的成本影响，即使继续投入已经不再合理。**不是因为值得才继续，是因为"都花了这么多了"。**

简单说：**"来都来了""买都买了""都在一起这么久了"——这些是沉没成本在替你思考。**

---

## 📖 经典实验

### 剧院票实验（Arkes & Blumer, 1985）

两组人买票：
- **A组**：花$100买了滑雪票
- **B组**：花$50买了另一张滑雪票（同一天）

结果：**大多数人选择去$100的那场**——不是因为更好玩，而是"更贵"。

理性决策应该选更好玩的那场，而不是更贵的那场。钱已经花了，回不来了。

## 🔍 沉没成本的"四大经典句式"

| 句式 | 潜台词 | 陷阱 |
|------|--------|------|
| **来都来了** | "虽然不好玩但都到了" | 继续浪费时间 |
| **买都买了** | "虽然不喜欢但不能浪费" | 继续用不合适的东西 |
| **都在一起这么久了** | "虽然不开心但不能分手" | 继续消耗的关系 |
| **都学了3年了** | "虽然不喜欢但不能放弃" | 继续不适合自己的方向 |

### 现实中的沉没成本

| 场景 | 沉没成本 | 理性决策 |
|------|---------|---------|
| **电影** | 买了票，但电影很难看 | 走人，去做更有价值的事 |
| **项目** | 投了100万，但前景不好 | 及时止损，转向新方向 |
| **工作** | 干了5年，但不开心 | 换工作，不看过去的5年 |
| **AI工具** | 学了一个月，但不适合你 | 换一个，不看过去的投入 |

## 🤖 AI与沉没成本

### AI帮你识别沉没成本陷阱

| 场景 | AI的作用 |
|------|---------|
| **项目评估** | 用AI做客观分析，排除情感滤镜 |
| **工具选择** | AI帮你快速测试多个方案，降低试错成本 |
| **内容创作** | AI帮你快速判断一篇文章是否值得继续 |
| **职业决策** | AI帮你做"如果不考虑已投入成本，我会怎么选"的分析 |

### 案例：用AI做"沉没成本检测"

```
提示词：
我在[项目/工作/关系]中已经投入了[时间/金钱/精力]。
现在继续的理由是"已经投入了这么多"。

请帮我做一个"沉没成本检测"：
1. 列出我已经无法回收的成本（这些不应该影响决策）
2. 如果我是今天刚接触这件事，我会怎么选择？
3. 给我一个"只看未来收益"的建议
```

## 💪 反制策略

### 3步跳出沉没成本陷阱

**第一步：识别沉没成本**
问自己：**"如果今天是第一次接触这件事，我还会开始吗？"**

> 如果答案是"不会"——你很可能被沉没成本绑架了。

**第二步：计算机会成本**
问自己：**"如果我把这些时间/金钱/精力用在别的地方，收益会更大吗？"**

> 继续一个不合适的AI工具 = 错过更适合的工具

**第三步：用AI做"归零分析"**

```
提示词：
假设我今天是完全归零的状态（没有历史投入），
面对当前的选择，请帮我：
1. 分析每个选项的未来收益
2. 不考虑我已经投入了什么
3. 给出纯粹基于未来价值的建议
```
