## 🔥 今日思维模型：幸存者偏差（Survivorship Bias）

**一句话解释**：你只看到活下来的人，没看到死掉的人——所以你以为成功很容易，其实只是死人不会说话。

---

## 💡 真实案例

你学公众号爆款经验：

> 你看10篇"10万+文章拆解" → 觉得写爆款有套路
> 但你没看到1000篇"阅读量0"的文章 → 它们没有拆解价值
> 
> **幸存者偏差的本质：你研究的是"活下来的人"，但失败者的教训更重要。**

**幸存者偏差的核心：成功者会被看见，失败者会消失。你看到的样本是有偏的。**

**在AI创业中：**

- 你学"AI工具月入10万" → 但99%的人没赚到钱
- 你学"知识星球年入百万" → 但大多数星球只有几十个用户
- 你学"短视频爆粉100万" → 但99.9%的视频播放量不到100

**记住：不要只学成功者的经验，要研究失败者的教训。**

## 🤖 AI实战应用

### 1. 用AI做"幸存者偏差检测器"

```
我想学XXX的成功经验
请帮我：
1. 这个成功案例的样本量有多大？
2. 失败率是多少？
3. 有哪些"沉默的失败者"我没看到？
4. 帮我找3个失败案例，分析他们为什么失败
```

### 2. 用AI做"失败案例分析器"

```
我在XXX领域想创业
请帮我：
1. 这个领域常见的失败原因有哪些？
2. 失败者最常犯的错误是什么？
3. 如何避免这些错误？
4. 帮我做一个"避坑清单"
```

### 3. 用AI做"真实成功率计算器"

```
我想做XXX（比如公众号/知识星球/AI工具）
请帮我：
1. 这个赛道的真实成功率是多少？（不是头部案例）
2. 中位数收益是多少？（不是平均数）
3. 我需要满足什么条件才能成为幸存者？
```
