## 🔥 今日思维模型：光环效应（Halo Effect）

**一句话解释**：因为某人在一个方面很厉害，你就觉得他所有方面都厉害。

---

## 💡 真实案例

一个名校毕业的创业者：

> 大家觉得他：聪明、能干、有远见、值得投资
> 实际发现：他执行力差、不善管理、团队流失率80%

**你因为"名校"这一个光环，自动给其他能力打了高分。**

**AI领域的光环效应：**

- 某个大V推荐了一个AI工具→你觉得一定好用→结果很难用
- 某个名校团队做了一个AI产品→你觉得一定靠谱→结果体验很差
- 某个AI公司融资1亿→你觉得它技术一定牛→结果核心能力是营销

**最危险的光环：**

- "大厂出品"≠好用（大厂也出过无数垃圾产品）
- "融资过亿"≠靠谱（融资多可能营销强，不是产品强）
- "粉丝百万"≠专业（粉丝多可能只是会营销）

---

## 🤖 AI实战应用

### 1. 用AI做"光环剥离分析"

```
我看到XXX（人/产品/公司）很厉害，因为TA在YYY方面很强
请帮我：
1. 列出TA所有让我觉得"厉害"的因素
2. 哪些是真实的证据？哪些是我的主观推断？
3. 如果去掉"光环标签"（名校/大厂/融资），还剩下什么？
4. 请给我一个客观的评估
```

### 2. 用AI做"决策去光环化"

```
我在考虑是否使用XXX工具，推荐它的人是YYY大V
请帮我：
1. 这个工具的真实功能是什么？
2. 它有没有客观的评测数据？
3. 有没有用户真实反馈？
4. 如果不考虑"谁推荐的"，它本身值不值得用？
```

### 3. 用AI做"自身光环检查"

```
我最近被人夸了（在XXX方面），请帮我检查：
1. 我是否因为这一个优点，开始忽视其他短板？
2. 团队/粉丝是否因为我的一个光环，对我有过高期待？
3. 我应该如何管理这种"光环预期"？
```

## 🎯 今日行动

1. **回想一次你被"光环"骗的经历**

4. **记住：一个人/产品/公司的真实价值，不在标签里，在细节里**
