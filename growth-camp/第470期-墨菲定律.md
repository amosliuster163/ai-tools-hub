## 🔥 今日思维模型：墨菲定律（Murphy's Law）

**一句话解释**：如果一件事有可能出错，那它早晚会出错——所以你要提前做好准备。

---

## 💡 真实案例

你的AI工具上线第一天：

> 你没做压力测试，觉得"应该不会出问题"
> 结果：第100个用户访问时，服务器崩了
> 墨菲定律：只要有可能出错的地方，最终一定会出问题

**墨菲定律不是诅咒，而是一种"底线思维"：**

- 你的小程序没做异常处理→用户输入了特殊字符→程序崩溃
- 你的公众号没提前准备选题→突然想不出写什么→断更
- 你的产品没做备份→服务器故障→数据丢失

**墨菲定律的本质：不要抱侥幸心理。**

## 🤖 AI实战应用

### 1. 用AI做"墨菲定律扫描"

```
我的项目/产品情况：XXX
请用墨菲定律帮我扫描：
1. 有哪些可能出错的地方？
2. 最坏情况下会发生什么？
3. 我应该如何提前预防？
4. 给我一个应急预案清单
```

### 2. 用AI做"容错方案设计"

```
我要上线XXX功能
请帮我设计容错方案：
1. 如果API挂了怎么办？
2. 如果用户输入异常数据怎么办？
3. 如果流量突然暴增怎么办？
4. 如果数据丢失了怎么办？

对每种情况，给我一个具体的应对方案。
```

### 3. 用AI做"检查清单生成器"

```
我要做一次重要的发布/上线/演讲
请帮我生成一个"墨菲检查清单"：
1. 技术层面：有哪些可能出问题？
2. 内容层面：有哪些可能出问题？
3. 时间层面：有哪些可能出问题？
4. 人员层面：有哪些可能出问题？

每个问题都要有对应的Plan B。
```
