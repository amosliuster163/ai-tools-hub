## 🔥 今日思维模型：锚定效应（Anchoring Effect）

**一句话解释**：人们在做决策时，会过度依赖第一个接触到的信息（锚点）。商家先标原价1999，再打折到999，你觉得便宜了——但可能它只值500。

---

## 💡 真实案例

你为什么觉得这个AI课程"很划算"？

> 课程页面写着：原价¥1999 → 限时特价¥299
> 你觉得省了1700块 → 但其实课程成本几乎为0
> 如果一开始就标¥299 → 你可能觉得"太便宜了，质量不行"
> 
> **那个"1999"就是锚，它让你对299产生了"超值"的错觉。**

**锚定效应的本质：大脑缺乏绝对判断能力，只能通过比较来做决策。第一个数字就是比较的基准。**

**在AI创业中：**

- 你给产品定价时：先想一个高价，再打折 → 客户觉得值
- 你和客户谈价时：先开价的人往往锚定了谈判区间
- 你评估AI工具时：先看到免费版本 → 付费版就觉得贵
- 你估算项目时间时：老板先说"一周能做完吧" → 你就按一周估

**记住：第一个数字不一定是真相，它可能只是一个心理陷阱。**

## 🤖 AI实战应用

### 1. 用AI做"锚定检测"

```
有人给我报了一个价格/方案/时间估算
请帮我：
1. 这个价格的合理区间应该是多少？（不看他的报价）
2. 我是不是被"第一个数字"影响了？
3. 抛开锚点，客观评估真实价值
```

### 2. 用AI做"定价策略"

```
我想给XXX产品/服务定价
请帮我：
1. 市场合理价格区间是多少？
2. 如何设置"锚点价格"让客户觉得划算？
3. 给我一个3档定价方案（低/中/高）
```

### 3. 用AI做"独立估值"

```
我要评估XXX（比如一个项目/一个工具/一个机会）
请帮我：
1. 不看别人给的估值，客观分析它的真实价值
2. 有哪些因素被高估了？哪些被低估了？
3. 给我一个"无锚定偏见"的评估报告
```
