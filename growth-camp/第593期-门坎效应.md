# 第593期：门坎效应

> **Yes to a small request → Yes to a bigger request.**

## 一句话总结

先让对方答应一个小请求，然后再提更大的——他更可能答应。

## 核心洞察

门坎效应是社会心理学最实用的技巧之一——**一旦一个人对你说了"是"，他对你的顺从度就会提高**。因为人们希望自己的行为保持一致。

### 经典实验

招牌实验：
- 一组人：直接请求在院子里放一个巨大的"安全驾驶"招牌 → 17%同意
- 另一组人：先请求在窗户上贴一个小标签 → 几乎所有人都同意
- 两周后，再请求放巨大招牌 → **76%同意**
- **仅仅因为先答应了一个小请求，同意率翻了4倍**

### 经典场景

**销售漏斗**
- 先让你免费试用 → 你用了一周 → 现在请付费升级
- 因为你已经"投资"了一周时间，放弃的成本变高了

**社交关系**
- 先帮一个小忙 → 关系破冰 → 后续合作更容易
- "能帮我看看这个文档吗？" → 看完后 "能帮我一起改吗？"

**内容创作**
- 先让用户点"赞" → 下次让他"关注" → 再下次让他"购买"
- 每一步都是一个"小门坎"

### 门坎效应的心理机制

**一致性原理**——人们希望自己的行为前后一致。一旦他对你说了"是"，再说"不"就会产生认知失调。

**自我认知**——"我帮了他一次，说明我愿意帮他/我喜欢这个人"

### 门坎效应 vs 拆解目标

门坎效应也可以反过来用在自己身上：
- 想养成一个习惯？先做一个"小到不可能失败"的版本
- 想每天运动？先从"每天做1个俯卧撑"开始
- 一旦开始了，你会自然做得更多

### 注意：门坎效应的伦理边界

- 用在自己身上：自我提升的工具
- 用在别人身上：影响可以，操纵不行
- 关键区别：你是否在帮对方做对他有利的决定

## AI实战应用

用AI帮你设计**门坎策略**：

```
我想让[目标群体]最终[大目标]。

请帮我设计门坎路径：
1. 最小的"第一步"是什么（几乎没人会拒绝）
2. 第二步、第三步分别是什么
3. 每一步的心理逻辑是什么
```
