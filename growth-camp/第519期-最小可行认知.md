## 🔥 今日思维模型：最小可行认知（Minimum Viable Knowledge）

**一句话解释**：你不需要100%准备好再开始，只需要60%的认知就足以做出第一次行动。先做再学，比先学再做快10倍。

---

## 💡 真实案例

你为什么迟迟不开始AI创业？

> 你想学完所有AI课程再开始 → 结果课程永远学不完
> 你想看完50篇教程再动手 → 结果一篇都没实践
> 你想等"准备好了"再做 → 结果等了半年还在准备
> 
> **真相是：你永远不可能"准备好"。最好的学习方式是在实践中学习。**

**最小可行认知的本质：知道 enough 就去做，在做的过程中补知识，效率最高。**

**在AI创业中：**

- 想做公众号？知道怎么写标题就行 → 先写10篇 → 再学排版/运营
- 想做AI产品？会调用API就行 → 先做出MVP → 再学架构/优化
- 想做知识星球？有内容就行 → 先建起来 → 再学营销/增长

**记住：完美是行动的敌人。完成比完美重要100倍。**

## 🤖 AI实战应用

### 1. 用AI做"60分启动方案"

```
我想做XXX（比如写公众号/做AI产品）
请帮我：
1. 启动这件事最核心的60%知识是什么？
2. 哪些知识可以等做了再学？
3. 给我一个"今天就启动"的最小方案
4. 哪些步骤是必须的，哪些是可有可无的？
```

### 2. 用AI做"行动优先学习路径"

```
我的目标是XXX
请帮我：
1. 第一个小行动应该是什么？（今天就能做）
2. 做完第一个行动后，我需要补什么知识？
3. 帮我设计一个"做→学→做"的循环路径
4. 不要让我先学完再做，让我边做边学
```

### 3. 用AI做"完美主义克星"

```
我在XXX事情上追求完美，导致迟迟不开始
请帮我：
1. 这件事的"60分版本"长什么样？
2. 完美主义在哪些地方拖了我的后腿？
3. 给我一个"今天就发布60分版本"的计划
4. 告诉我为什么"完成"比"完美"重要
```
