# 第660期：反馈回路

> **一句话理解**：你做的每一件事，都会通过某种方式"反馈"回来影响你。

## 核心概念

**反馈回路（Feedback Loop）**是系统思维的核心概念：行为产生结果，结果反过来影响行为。

有两种反馈回路：
- **正反馈（增强回路）**：行为让结果变好 → 结果好让你做更多 → 螺旋上升（或下降）
- **负反馈（平衡回路）**：行为让结果偏离目标 → 系统自动修正 → 保持稳定

## 经典案例

**复利增长**：
> 学习 → 能力提升 → 收入增加 → 有钱投资学习 → 能力更强
> 这是正反馈回路，一旦启动就加速。
> 
> 但反过来也一样：
> 不学习 → 能力下降 → 收入减少 → 没钱学习 → 能力更差
> 这也是正反馈回路，只不过是向下的。

**产品迭代**：
> 用户反馈 → 改进产品 → 更多用户 → 更多反馈 → 更好产品
> 好的创业公司都有这个正反馈回路。
> 
> 但如果：
> 用户流失 → 收入减少 → 裁员 → 产品变差 → 更多用户流失
> 这就是死亡螺旋。

## 5秒行动

找到你生活中的一个正反馈回路，然后加速它。
