## 🔥 今日思维模型：踢猫效应（Kick the Cat Effect）

**一句话解释**：负面情绪会沿着社会等级向下传递。老板骂你，你不敢回嘴 → 回家骂老婆 → 老婆骂孩子 → 孩子踢猫。你是情绪链条上的一环，既是受害者也是加害者。

---

## 💡 真实案例

为什么你的一条差评能毁掉你一天的心情？

> 你的AI课程被给了一个差评 → 你很生气
> 你把气撒在了社群里 → 对一个提问不耐烦
> 那个提问的用户很不爽 → 给了你另一个差评
> 
> **负面情绪像病毒，从一个节点传到下一个节点。**

**踢猫效应的本质：人们不敢对"比自己强"的发火，就会对"比自己弱"的发火。情绪向下传染，直到最弱的一环。**

**在AI创业中：**

- 平台的政策变化让你不爽 → 你对用户态度变差 → 用户流失
- 竞品的恶意竞争让你焦虑 → 你对合作伙伴没耐心 → 合作破裂
- AI工具的一个bug让你抓狂 → 你对社群成员敷衍 → 社群活跃度下降

**记住：情绪管理是创业的第一课。学会切断情绪传染链条。**

## 🤖 AI实战应用

### 1. 用AI做"情绪链条识别"

```
我今天心情不好，因为XXX
请帮我：
1. 我的负面情绪会传递给谁？
2. 我是不是"踢猫效应"的一环？
3. 我如何切断这个链条？
```

### 2. 用AI做"情绪应急处理"

```
我现在很愤怒/焦虑/沮丧
请帮我：
1. 冷静10分钟后再做决定
2. 帮我想3个"不把情绪传给别人"的方法
3. 帮我分析：我的情绪是来自当前的事，还是"上游"传来的？
```

### 3. 用AI做"社群情绪管理"

```
我的社群里有人发了负面情绪
请帮我：
1. 如何避免负面情绪在社群中传染？
2. 我应该介入还是不介入？
3. 帮我设计一个"社群情绪管理SOP"
```
