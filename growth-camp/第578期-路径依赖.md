# 第578期：路径依赖

> **History matters. Where you started shapes where you can go.**

## 一句话总结

你过去的选择会限制你未来的选择，即使那些过去已经不重要了。

## 核心洞察

路径依赖的核心逻辑是：**一旦你走上某条路，转弯的成本会越来越高，直到你被这条路锁死**。不是因为这条路最好，而是因为换路的代价太大了。

### 经典场景

**QWERTY键盘布局**
- 1868年设计，初衷是**防止打字机卡键**（故意把常用字母分开）
- 现在打字机早就不卡键了，但我们还在用这个布局
- 因为全世界都学会了，重新培训的成本太高

**技术栈选择**
- 创业初期选了PHP（因为招人多、上手快）
- 公司做大了想换成更先进的技术 → 发现整个团队都要重学
- 最后继续用PHP，不是因为PHP最好，是因为换不起

**职业路径**
- 第一份工作选了某个方向
- 第二份工作受第一份影响（经验和简历）
- 第三份又受第二份影响……十年后你在这个方向上了
- 不是因为你最喜欢这个方向，是因为你"已经在"这个方向了

### 路径依赖的三个关键阶段

1. **偶然起点**：最初的选择可能只是因为当时的特殊情况
2. **正反馈**：越往前走，投入越多，这条路看起来越"正确"
3. **锁定效应**：换路成本高到无法承受，即使你知道有更好的路

### 如何识别和打破路径依赖

**定期做"如果从零开始"的假设**
- 问自己：如果今天我从零开始，我还会选这条路吗？
- 如果答案是否定的，说明你可能被路径依赖锁住了

**在小范围试错**
- 不要一下子全换，先在小事上试试别的路
- 用副业测试新方向，用业余时间学习新技能

**设置"换路检查点"**
- 每半年或一年，主动审视一次自己的方向
- 不要等到十年后才想"我是不是选错了"

## AI实战应用

用AI帮你做**路径依赖审视**：

```
我目前在[职业/项目/技术栈/生活方式]上已经走了[X年]。

请帮我做路径依赖分析：
1. 我当初选择这条路的原因是什么？（写下来）
2. 这些原因现在还成立吗？
3. 如果今天从零开始，我会怎么选？
4. 换路的成本有哪些？有没有降低成本的渐进方式？
```

你现在的方向，是你主动选择的，还是被过去的选择推着走的？
