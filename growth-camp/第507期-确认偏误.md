## 🔥 今日思维模型：确认偏误（Confirmation Bias）

**一句话解释**：你不是在寻找真相，你是在寻找"能证明自己是对的"的证据——大脑自动过滤反面信息。

---

## 💡 真实案例

你觉得AI会取代你的工作：

> 你看到"AI取代100万岗位" → 收藏转发
> 你看到"AI创造200万新岗位" → 直接划过
> 
> **确认偏误的本质：你不是在获取信息，你是在加固自己的信念。**

**确认偏误的核心：大脑会主动寻找支持自己观点的证据，忽略或贬低反面证据。**

**在AI创业中：**

- 你觉得公众号能火 → 只看成功案例，忽略99%失败的人
- 你觉得某个工具不好用 → 只看差评，无视好评
- 你觉得用户不喜欢你的产品 → 只关注投诉，无视夸奖

**记住：最危险的不是不知道，是以为自己知道，其实只是选择性相信。**

## 🤖 AI实战应用

### 1. 用AI做"确认偏误检测器"

```
我相信XXX
请帮我：
1. 列出3个支持这个观点的证据
2. 列出3个反对这个观点的证据（强制）
3. 我是不是在忽略反面证据？
4. 帮我用反方视角重新分析这个问题
```

### 2. 用AI做"反方视角训练器"

```
我认为XXX是最好的选择
请帮我：
1. 如果我完全错了，会是因为什么？
2. 反方最有力的3个论点是什么？
3. 帮我在反方立场写一段论证
```

### 3. 用AI做"信息多元化助手"

```
我在研究XXX领域
请帮我：
1. 列出这个领域的3种不同观点
2. 每种观点的核心论据是什么？
3. 帮我找到可能被忽略的反面信息
```
