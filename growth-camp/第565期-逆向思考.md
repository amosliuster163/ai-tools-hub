# 第565期：逆向思考

> **Invert, always invert.** —查理·芒格

## 一句话总结

想不清楚怎么成功，就先想想怎么才能不失败。

## 核心洞察

逆向思考是芒格最爱的思维模型——正向思考问"怎么做才能赢"，逆向思考问"怎么做才不会输"。

### 经典场景

**想做好一个产品**
- 正向：怎么让用户喜欢？
- 逆向：**怎么让用户一定讨厌？**（慢、难用、经常出bug、找不到客服）
- 然后避免这些事

**想维持好一段关系**
- 正向：怎么让对方开心？
- 逆向：**怎么做对方一定会离开？**（不信任、不尊重、冷暴力、说话不算数）
- 然后不做这些事

**想做好内容创作**
- 正向：怎么写爆款？
- 逆向：**怎么写一定没人看？**（标题无聊、内容注水、自说自话、没有实用价值）
- 然后避开这些坑

### 为什么逆向思考有效

1. **避免失败比追求成功更可控**——失败的路径是清晰的，成功的路径有太多变量
2. **人类天生对负面信息更敏感**——知道"什么不能做"比知道"该做什么"更容易执行
3. **排除法缩小了选择范围**——先去掉明显错误的选项，剩下的即使不完美也不至于太差

### 芒格的三步逆向法

**第一步：定义目标**
- "我想在三年内把公众号做到10万粉丝"

**第二步：逆向思考——什么会导致失败？**
- 内容质量不稳定
- 更新频率太低
- 不研究用户喜好
- 被平台限流
- 被竞品超越

**第三步：制定避免这些失败的具体行动**
- 每周固定更新3篇（解决频率问题）
- 建立选题库和写作模板（解决质量问题）
- 每月分析一次数据（解决用户喜好问题）

### AI时代的逆向思考

AI特别擅长做"逆向分析"——你可以让它帮你列出"一定会失败的N种做法"，然后逐一规避。

## AI实战应用

用AI做**失败预演**：

```
我的目标是：[你的目标]

请用逆向思考帮我分析：
1. 列出至少8种"一定会导致失败"的做法
2. 每种做法对应的现实案例是什么
3. 我应该怎么提前避免

要求：越具体越好，不要说空话。
```

## 每日思考

你现在最重要的那个目标，什么情况下**一定会失败**？列出来，然后一一避免。
