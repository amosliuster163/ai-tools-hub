# 第619期：反馈回路

> **Your output becomes your input. The loop shapes you.**

## 一句话总结

你的行为产生结果，结果影响你下一次的行为——这就是反馈回路。

## 核心洞察

反馈回路是系统思维的核心概念——**在闭环系统中，结果会反过来影响原因，形成自我强化或自我调节的循环**。理解反馈回路，你就能理解为什么有些系统越来越极端，有些却能自动平衡。

### 两种反馈回路

**正向反馈回路（自我强化）**
- 越有钱 → 越能投资 → 越有钱
- 越受欢迎 → 更多人关注 → 更受欢迎
- 结果：指数增长或崩溃

**负向反馈回路（自我调节）**
- 太热 → 开空调 → 温度下降 → 关空调
- 饿了 → 吃饭 → 饱了 → 停止
- 结果：稳定、平衡

### 经典场景

**社交媒体算法**
- 你点击了某类内容 → 算法推荐更多 → 你点击更多 → 信息茧房形成
- 这是一个正向反馈回路：越来越极端

**财富积累**
- 复利是正向反馈回路的典型
- 收益产生更多收益

**团队士气**
- 团队赢了 → 士气提高 → 表现更好 → 继续赢
- 团队输了 → 士气降低 → 表现更差 → 继续输

### 如何利用反馈回路

**建立正向回路**
- 创造"赢→信心→更赢"的循环
- 从一个小胜利开始

**打破负向回路**
- 识别当前的负向循环
- 在某个环节插入外部干预
