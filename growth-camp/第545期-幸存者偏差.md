## 🔥 今日思维模型：幸存者偏差（Survivorship Bias）

**一句话解释**：你只看到成功的人说什么，看不到失败的人为什么不说话。二战时军方发现飞机机翼弹孔最多，想加固机翼。统计学家说"不，加固没有弹孔的地方"——因为中弹的飞机没回来。

---

## 💡 真实案例

为什么你看了100篇"我用AI月入10万"的文章，自己却做不到？

> 你看到100个成功案例 → 你觉得"AI创业很容易"
> 但你没看到10000个失败的人 → 他们在沉默
> 
> **你根据幸存者做判断，就像根据回来的飞机做防御方案——完全错误。**

**幸存者偏差的本质：失败者不说话。沉默的大多数才是真实数据。**

**在AI创业中：**

- 你看到有人做AI课程赚了100万 → 但1000个做课程的人赔了钱
- 你看到有人靠AI写作自由职业 → 但90%的自由者收入不稳定
- 你看到有人用AI做号涨粉10万 → 但99%的号只有几百粉丝

**记住：看成功案例的同时，更要看失败案例。幸存者不是全部。**

## 🤖 AI实战应用

### 1. 用AI做"沉默数据搜索"

```
我想了解XXX领域（比如AI课程创业）
我只看到了成功案例
请帮我：
1. 这个领域的失败率是多少？
2. 失败者通常犯什么错？
3. 沉默的大多数在做什么？
4. 给我一个"幸存者+失败者"的全景分析
```

### 2. 用AI做"真实概率评估"

```
我看到很多人通过XXX成功了
请帮我：
1. 这个"很多人"占所有尝试者的百分比是多少？
2. 真实的成功率有多大？
3. 如果我随机一个人去做，成功概率是多少？
```

### 3. 用AI做"失败案例收集"

```
我想进入XXX领域
请帮我：
1. 找10个在这个领域失败的真实案例
2. 他们的共同失败原因是什么？
3. 我如何避免这些坑？
4. 失败者给出的"教训"是什么？
```
