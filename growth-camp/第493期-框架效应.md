## 🔥 今日思维模型：框架效应（Framing Effect）

**一句话解释**：同一件事，用不同的方式描述，你的决定会完全不同。

---

## 💡 真实案例

你看到一个AI产品的定价：

> "成功率90%" → 你买了
> "失败率10%" → 你没买
> 
> 但90%成功率 = 10%失败率，完全一样的数据。
> 不同的是"框架"——一个强调成功，一个强调失败。

**框架效应的本质：人们不是被事实影响，而是被事实的呈现方式影响。**

**在AI创业中：**

- "年付¥799（省¥389）" → 你觉得划算 → 比"月付¥99"更容易让人选
- "已有10000人加入" → 你觉得靠谱 → 比"刚上线的新产品"更容易让人信
- "99%的用户都说好" → 你觉得好 → 比"1%的用户不满意"更容易让人买

**记住：同样的事实，不同的框架 = 不同的结果。用好框架效应，但不要滥用。**

## 🤖 AI实战应用

### 1. 用AI做"框架效应检测器"

```
我看到一个信息：XXX
请帮我分析：
1. 这个信息是用什么框架呈现的？
2. 如果换一种框架，我的感受会不同吗？
3. 事实本身是什么？（去掉框架后的原始数据）
4. 帮我做一次"去框架化"分析
```

### 2. 用AI做"营销框架优化器"

```
我想推广XXX产品/服务
请帮我用框架效应优化：
1. 当前描述是什么框架？
2. 有哪些更好的框架选择？
3. 哪种框架最能打动目标用户？
4. 帮我写出3个不同框架的文案
```

### 3. 用AI做"决策去偏见工具"

```
我要做一个重要决定
请帮我：
1. 我的决定是否受到了框架效应影响？
2. 如果去掉所有框架，只看事实，我的决定会不同吗？
3. 帮我用不同框架重新呈现这个决定
4. 帮我做一次"去框架化"的理性分析
```
