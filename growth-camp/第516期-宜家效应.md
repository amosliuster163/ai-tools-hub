## 🔥 今日思维模型：宜家效应（Ikea Effect）

**一句话解释**：人们对自己投入劳动的产品，会给予更高的价值评价。你自己组装的宜家家具，哪怕歪歪扭扭，你也觉得比成品家具好。

---

## 💡 真实案例

你为什么舍不得删那个没人用的AI工具？

> 你花了3天搭建的Notion模板 → 其实市面上有更好用的 → 但你不想换
> 你花了一周写的AI提示词 → 效果一般 → 但你总觉得"这是我做的"
> 你手动整理的客户表格 → 明明可以自动化 → 但你觉得"亲手做的更有感觉"
> 
> **这就是宜家效应在作祟：投入的劳动让你高估了产出的价值。**

**宜家效应的本质：我们容易混淆"投入感"和"真实价值"。不是因为好才喜欢，而是因为喜欢才觉得好。**

**在AI创业中：**

- 你花一个月做的产品 → 用户不买账 → 你觉得"他们不懂"
- 你辛苦写的公众号文章 → 阅读量低 → 你觉得"内容好就行"
- 你手动做的运营流程 → 效率低 → 但你觉得"这是我的心血"

**记住：市场不关心你投入了多少，只关心产品有没有价值。学会用用户视角评估，而不是投入者视角。**

---

## 🤖 AI实战应用

### 1. 用AI做"客观价值评估"

```
这是我做的XXX产品/内容/项目
请帮我：
1. 站在完全不了解我的用户角度，客观评价
2. 市场上有没有更好的替代方案？
3. 我的真实竞争力在哪里？
4. 哪些部分值得保留，哪些该砍掉？
```

### 2. 用AI做"投入产出比分析"

```
我在XXX项目上投入了[时间/精力/金钱]
请帮我：
1. 实际产出是多少？（用数据衡量）
2. 投入产出比是多少？
3. 如果重来一次，我会怎么做更高效的方案？
4. 有哪些投入是"宜家效应"造成的浪费？
```

### 3. 用AI做"断舍离助手"

```
我有这些项目/工具/内容在维护
请帮我：
1. 哪些真的有价值？（不看我的投入）
2. 哪些应该放弃？（哪怕我投入了很多）
3. 帮我做一个"该保留vs该砍掉"的清单
```
