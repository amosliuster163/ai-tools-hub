# 第604期：机会成本

> **Every choice has a cost — the value of what you give up.**

## 一句话总结

做一件事的真正成本，不是你花了多少钱，而是你放弃了什么更好的选择。

## 核心洞察

机会成本是经济学最核心的概念之一——**资源是有限的，你选择了A就必然放弃B、C、D。被放弃的那个"最好的替代选项"的价值，就是你的机会成本**。

### 经典场景

**读大学的成本**
- 不是学费+生活费（显性成本）
- 而是：如果你不上大学，这4年你能赚到的钱+积累的经验
- **真正的成本远比你想象的高**

**创业的机会成本**
- 你辞职创业，不只是为了启动资金
- 你还放弃了：稳定的薪水、晋升机会、人脉积累
- 所以创业必须创造比这些更大的价值

**时间的使用**
- 刷2小时短视频的成本
- 不是手机电费，而是你用这2小时本可以学到的东西
- 时间是最不可再生的资源

### 机会成本的三个特征

1. **隐形的**——你不会在账本上看到它
2. **因人而异**——同一个选择，不同人的机会成本不同
3. **动态的**——随着你的能力提升，机会成本也在变化

### 如何用机会成本做决策

**每次做选择前问自己**
1. 我做这件事，放弃了什么？
2. 被放弃的选项里，最有价值的是什么？
3. 当前选择的价值 > 机会成本吗？

## AI实战应用

```
我正在考虑做[某件事]。

请帮我分析：
1. 做这件事的显性成本是什么
2. 机会成本是什么（我放弃的最佳替代选项）
3. 有没有更低成本的方式达到同样的目的
```

## 每日思考

你今天花时间做的哪件事，机会成本最高？
