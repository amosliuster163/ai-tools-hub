---

## 🔥 今日思维模型：晕轮效应（Halo Effect）

**一句话解释**：一个人有一个突出的优点，你就会认为他在其他方面也很优秀。一个AI博主文章写得好 → 你觉得他的产品一定好 → 觉得他的商业思维一定好 → 觉得他整个人都厉害。

---

## 💡 真实案例

为什么你容易被"某方面很强"的人骗？

> 一个AI技术大牛 → 技术确实牛 → 你信任他 → 他推荐你投资一个项目
> → 你投了 → 亏了 → 因为他不懂商业，只懂技术
> 
> **你被他的"技术光环"蒙蔽了双眼，忽略了他可能不懂商业的事实。**

**晕轮效应的本质：大脑喜欢"简单归类"。一个亮点照亮一切，让你看不到阴影。**

**在AI创业中：**

- 一个工具UI好看 → 你觉得它功能一定好 → 实际可能很弱
- 一个博主粉丝多 → 你觉得他一定专业 → 可能只是会营销
- 一个课程价格高 → 你觉得一定值 → 可能只是定价策略

**记住：一个优点不等于全面优秀。学会"去光环化"看人看事。**

### 1. 用AI做"去光环分析"

```

```

### 2. 用AI做"盲点搜索"

```
我非常信任XXX
请帮我：
1. 我可能忽略了哪些风险？
2. 这个信任有没有"光环效应"的成分？
3. 帮我找出3个"我不愿意看到但可能存在"的问题
```

### 3. 用AI做"反向光环利用"

```
我想让自己看起来更专业
请帮我：
1. 如何设计一个"晕轮效应"？（一个突出的亮点带动整体印象）
2. 哪些"亮点"最容易让人产生全面信任？
3. 帮我设计一个"亮点策略"
```
