## 💡 今日模型：基本归因错误（Fundamental Attribution Error）

**定义**：解释他人行为时，我们倾向于**高估性格因素、低估情境因素**。但解释自己行为时恰恰相反——我们总能找到情境的理由。

简单说：**别人迟到是态度问题，我迟到是路上太堵。**

---

## 📖 经典实验

### 哈佛演讲实验（Jones & Harris, 1967）

两组学生听同一个演讲，内容是支持古巴卡斯特罗。

- **A组被告知**：演讲者是**自愿选择**支持卡斯特罗
- **B组被告知**：演讲者是**被随机分配**到这个立场的

结果：即使B组知道演讲者是被迫的，**仍然认为他内心是支持卡斯特罗的**。

**人们无法忽视行为本身，即使知道情境强迫，仍然把行为归因于性格。**

## 🔍 日常生活中的归因错误

### 双标归因表

| 行为 | 别人做了（归因于性格） | 我做了（归因于情境） |
|------|---------------------|-------------------|
| 迟到 | "他总是不守时" | "今天堵车太严重了" |
| 发火 | "他脾气太差了" | "今天压力太大了" |
| 犯错 | "他能力不行" | "这个任务本来就不合理" |
| 成功 | "他运气好" | "我努力了很久" |
| 沉默 | "他性格孤僻" | "我需要独处充电" |

**看出来了吗？同样的行为，对别人和对自己的解释完全相反。**

## 🤖 AI与归因错误

### AI放大了这个问题

| 场景 | AI如何放大归因错误 |
|------|-------------------|
| **社交媒体** | 算法推荐极端内容，让你看到更多"别人犯蠢"的例子 |
| **AI翻译聊天** | 失去语气和表情，更容易把别人的文字理解为"态度问题" |
| **AI简历筛选** | 只看关键词，忽略了候选人的真实能力背景 |
| **客服机器人** | 用户把机器人的"死板"归因为"公司不重视客户" |

### 案例：AI客服的归因困境

```
用户：为什么我的订单还没到？
AI：根据物流信息，预计明天送达。
用户：你们的服务态度真差！
```

用户把"AI回答简短"归因为"服务态度差"，
但实际上是**AI的能力限制**，不是态度问题。

## 💪 反制策略

### 3步归因校正法

**第一步：角色互换**
问自己："如果我做了同样的事，我会怎么解释？"

> 如果他迟到，你觉得是他态度问题。
> 如果你迟到，你会说是堵车。
> → 他可能也堵车了。

**第二步：情境清单**
列出3个可能的外部原因，再下判断。

| 行为 | 可能的3个情境原因 |
|------|-----------------|
| 同事没回消息 | 1.在开会 2.手机没电 3.消息太多漏看了 |
| 客户不满意 | 1.需求没对齐 2.期望值过高 3.之前有过不愉快 |
| 朋友没点赞 | 1.没刷到 2.不想社交 3.在忙 |

**第三步：AI辅助客观分析**
把情况描述给AI，让它从第三方视角分析，排除你的情绪滤镜。

```
提示词：同事今天开会没发言，平时他很积极。请从客观角度
分析5种可能的原因，不要默认是态度问题。
```

## 🛠️ AI实战：用AI做归因校正

**任务**：每次想评判别人之前，先用AI做3分钟归因分析

```
提示词：
情境：[描述具体事件]
我的第一反应：[写下你的归因]

请帮我：
1. 列出3个可能的客观原因
2. 如果我是对方，我会怎么解释这个行为
3. 指出我的判断中可能存在的情绪滤镜
```

**坚持一周**：你会发现自己对别人的"误判率"大幅下降。
