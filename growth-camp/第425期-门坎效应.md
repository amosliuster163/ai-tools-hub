## 💡 今日模型：门坎效应（Foot-in-the-Door Effect）

**定义**：一个人一旦接受了一个小请求，**就更有可能接受随后更大的请求**。先让你跨过一个低矮的门坎，再让你走进一扇大门。

简单说：**"先帮我拿个东西"（小请求）→ "能帮我搬个家吗？"（大请求）——你更容易答应。**

---

## 📖 经典实验

### 弗里德曼实验（1966）

研究人员在加州某社区做实验：

**第一组（直接请求）**：
直接问居民："愿不愿意在你家院子里放一个大'安全驾驶'广告牌？"
**同意率：17%**

**第二组（门坎请求）**：
先问："愿不愿意在窗户上贴一个小小的'安全驾驶'贴纸？"（几乎所有人都同意了）
两周后，再问："愿不愿意放那个大广告牌？"
**同意率：55%**

**同样的请求，只是加了一个小步骤，同意率翻了3倍。**

## 🔍 门坎效应的日常应用

| 场景 | 小请求（门坎） | 大请求（目标） |
|------|-------------|-------------|
| **销售** | "先试用3天免费" | 购买年费会员 |
| **社交** | "能加个微信吗" | 约出来吃饭 |
| **职场** | "帮我看看这段文字" | "帮我改完整个方案" |
| **社群运营** | "先加群看看" | 购买付费课程 |
| **恋爱** | "一起喝杯咖啡" | 确定关系 |

### 为什么门坎效应有效？

**两个心理机制**：

| 机制 | 说明 |
|------|------|
| **自我认知一致性** | "我答应了他一次→我是一个愿意帮忙的人→我应该继续帮忙" |
| **承诺升级** | 一旦做出承诺，人们倾向于保持承诺的一致性 |

### 你也可以用AI实践门坎效应

**正向应用**：让AI帮你设计一个"渐进式"的成长路径

```
任务：培养每天阅读的习惯

❌ 直接请求：
"从今天开始每天读2小时" → 做不到 → 放弃

✅ 门坎策略：
第1周：每天读5分钟（小门坎）
第2周：每天读15分钟（跨入门坎）
第3周：每天读30分钟（走进房间）
第4周：每天读1小时（到达目标）
```

## 💪 应用策略

### 3步用门坎效应改变自己

**第一步：把大目标拆成"第一个门坎"**

| 大目标 | 第一个门坎 |
|--------|-----------|
| "我要用AI提升效率" | 今天用AI写一封邮件 |
| "我要开始创业" | 今天写下你的第一个商业想法 |
| "我要健身" | 今天做5个俯卧撑 |
| "我要学英语" | 今天背3个单词 |

**第二步：用AI做"门坎设计师"**

```
提示词：
我想达成[大目标]，请帮我设计一个门坎策略：
1. 第一个最小的请求是什么？（5分钟内能完成）
2. 第二个小请求是什么？
3. 如何逐步升级直到达成大目标？
```

**第三步：利用一致性心理**
每完成一个小步骤，**记录并庆祝**——这会强化你的"我是一个能做到的人"的自我认知。
