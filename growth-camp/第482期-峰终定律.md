## 🔥 今日思维模型：峰终定律（Peak-End Rule）

**一句话解释**：你对一段经历的评价，只取决于最强烈的瞬间（峰值）和结束时的感觉（终值），而不是全程的平均感受。

---

## 💡 真实案例

你和用户的第一次互动：

> 整个使用过程很顺畅，但最后一步报错了 → 用户觉得"这个产品很烂"
> 
> 或者反过来：
> 中间出了几个小问题，但最后给了一个超预期的结果 → 用户觉得"这个产品不错"

**峰终定律的本质：记忆不是录像带，而是照片集——你只记住最精彩的那张和最后一张。**

**在AI创业中：**

- 你的AI工具90%的时间好用，10%报错 → 用户记住的是报错那10%
- 你的公众号文章前面平淡，最后给了一个金句 → 用户觉得"这篇文章有深度"
- 你的服务全程一般，但最后送了一个小惊喜 → 用户觉得"服务超预期"

**记住：你不需要让全程都完美，你只需要制造好的峰值和好的终值。**

```

4. 帮我设计一个具体的峰值方案
```

### 3. 用AI做"终值优化器"

```

请帮我优化终值：
1. 当前的终值给用户的感受是什么？
2. 如何设计一个让用户记住的好终值？
3. 有哪些行业经典的"好终值"设计？
4. 帮我重新设计终值体验
```
