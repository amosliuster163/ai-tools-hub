# 第614期：皮格马利翁效应

> **You become what others expect you to become.**

## 一句话总结

你对一个人的期望，会不自觉地让那个人变成你期望的样子。

## 核心洞察

皮格马利翁效应（也叫罗森塔尔效应）揭示了一个强大的心理学现象——**期望本身就是一种力量**。老师对学生的期望、领导对员工的期望、父母对孩子的期望，都会成为一种隐性的"自我实现预言"。

### 经典实验

1968年罗森塔尔的小学实验：
- 随机选了一些学生，告诉老师"这些学生智商很高，潜力巨大"
- 实际上这些学生是随机选的，没有任何特殊之处
- 8个月后，这些学生的成绩确实显著提高了
- **老师的高期望改变了教学方式，进而改变了学生**

### 经典场景

**职场管理**
- 领导觉得某个员工不行 → 给他少派活、少关注 → 员工真的变差了
- 领导觉得某个员工行 → 给他更多机会和挑战 → 员工真的成长了
- 两种情况下，员工的天赋没变，变的只是领导的期望

**亲密关系**
- 你觉得伴侣不够好 → 你的态度传达出不满 → 伴侣变得防御或退缩
- 你相信伴侣有潜力 → 你的态度传达出信任 → 伴侣更有自信去尝试

**自我期望**
- 你觉得自己做不到 → 你的行为会不自觉地验证这个信念
- 你相信自己能成长 → 你会更愿意尝试和学习

### 皮格马利翁效应的两个方向

**正向循环**：高期望 → 更多支持 → 更好表现 → 更高期望
**负向循环**：低期望 → 更少关注 → 更差表现 → 更低期望

### 如何主动利用皮格马利翁效应

**作为管理者/老师/父母**
- 对团队成员表达真实的、合理的高期望
- 然后给他们匹配的支持和资源
- 不要只期望，不投入

**作为个人**
- 注意你给自己的期望是正向还是负向的
- 你对自己的期望就是一种内在的皮格马利翁效应

**作为朋友/伴侣**
- 用积极的期望影响身边的人
- 但要区分"积极期望"和"不切实际的要求"

