## 🔥 今日思维模型：门坎效应（Foot-in-the-Door Effect）

**一句话解释**：别人先让你答应一个小请求，然后你会更容易答应一个大请求——因为你想保持一致性。

---

## 💡 真实案例

你被一个销售套路了：

> 销售："能占用你1分钟吗？" → 你答应了
> 销售："那你看看这个产品？" → 你看了看
> 销售："免费试用一下？" → 你试了
> 销售："现在购买有优惠哦" → 你买了
> 
> 回想起来，你根本不需要这个产品。

**门坎效应的本质：一旦你迈过了第一个门坎，后面的门坎就越来越难拒绝——因为你想"保持一致"。**

**在AI创业中：**

- 用户免费用了你的工具 → 觉得好用 → 你推出付费版 → 他付费了
- 你先关注了一个公众号 → 然后加了社群 → 然后买了课程 → 然后买了进阶课
- 你先试了一个AI小功能 → 觉得不错 → 然后买了会员 → 然后买了年费

**记住：门坎效应本身没有好坏。你可以用它做营销，也要防被别人用它套路你。**

## 🤖 AI实战应用

### 1. 用AI做"门坎效应检测器"

```
我最近答应了XXX，然后对方又让我做XXX
请帮我分析：
1. 我是否陷入了门坎效应？
2. 如果从一开始就知道最终请求，我还会答应吗？
3. 我如何在不破坏关系的情况下拒绝？
4. 帮我设计一个"守住门坎"的策略
```

### 2. 用AI做"营销阶梯设计"

```
我想让用户从免费用户变成付费用户
请帮我用门坎效应设计一个转化路径：
1. 第一个小请求是什么？（最低阻力）
2. 第二个中等请求是什么？
3. 最终的付费请求是什么？
4. 每个步骤之间的"一致性钩子"是什么？
```

### 3. 用AI做"反套路防护"

```
我经常被别人"一步一步说服"
请帮我：
1. 识别常见的门坎套路
2. 如何在第一步就判断最终目的？
3. 有哪些话术可以优雅地拒绝后续请求？
4. 帮我建立一个"反门坎"思维框架
```
