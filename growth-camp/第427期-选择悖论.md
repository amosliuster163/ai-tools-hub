## 💡 今日模型：选择悖论（Paradox of Choice）

**定义**：更多的选择并不总是更好。**选项太多反而会让人焦虑、降低满意度**，甚至导致无法做出任何选择。

简单说：**果酱店有3种口味你秒选，有24种口味你站10分钟最后空手走人。**

---

## 📖 经典实验

### 果酱实验（2000）

哥伦比亚大学希娜·艾扬格做了一个经典实验：

**场景A**：超市展台放**6种果酱**
- 30%的顾客停下来试吃
- **购买率：30%**

**场景B**：超市展台放**24种果酱**
- 60%的顾客停下来试吃（吸引力更高！）
- **购买率：3%**

**选项多了4倍，购买率反而只有1/10。**

## 🔍 选择悖论的日常表现

| 场景 | 少量选择的感受 | 大量选择的感受 |
|------|-------------|-------------|
| **Netflix选片** | 3部电影→爽快看 | 3000部电影→刷20分钟→关掉 |
| **餐厅点菜** | 8道菜→轻松选 | 80道菜→翻来翻去→还是不知道吃啥 |
| **买衣服** | 3个颜色→选一个 | 30个颜色→纠结到放弃 |
| **选职业** | 2个方向→果断选 | 20个方向→焦虑到睡不着 |
| **AI工具选择** | 2个工具→开干 | 200个工具→全在试，没一个深入 |

### 为什么选择多了反而不好？

**三大心理机制**：

| 机制 | 说明 |
|------|------|
| **分析瘫痪** | 选项太多→大脑超载→无法决策 |
| **机会成本焦虑** | "选了这个就意味着错过其他19个" |
| **后悔预期** | "万一另一个更好呢？" |

```
2. 给出明确的推荐
3. 告诉我"选完之后不要回头看"的理由
```

## 💪 应用策略

### 3步用AI对抗选择悖论

**第一步：用AI做"减法"**

```
提示词：
我有[数字]个想法/选项，请帮我：
1. 选出最重要的3个
2. 告诉我为什么其他的可以先放一放
3. 给出一个"现在就开始做X"的理由
```

**第二步：设定"选择截止线"**

| 场景 | 截止线 |
|------|--------|
| 选AI工具 | 试3天→定1个→不换了 |
| 选创业项目 | 调研1周→定1个→开干 |
| 选学习方法 | 试1个课程→坚持30天→不看其他的 |

**第三步：用"满意即可"代替"最优选择"**

```
❌ "我要找到最好的AI工具"
✅ "我要找到一个够用的AI工具"

❌ "我要写出最完美的文章"
✅ "我要写出一篇能发布的文章"
```
