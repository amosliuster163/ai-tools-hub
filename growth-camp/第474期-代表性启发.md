## 🔥 今日思维模型：代表性启发（Representativeness Heuristic）

**一句话解释**：你根据"看起来像不像"来判断一件事的概率——但这经常导致错误。

---

## 💡 真实案例

你在招聘一个AI产品经理：

> 候选人A：30岁，男性，理工科背景，说话逻辑清晰
> 候选人B：28岁，女性，文科背景，说话感性
> 
> 你觉得A更像"AI产品经理"
> 
> 但B可能更适合——因为AI产品最需要的是理解用户，而文科背景的人往往更擅长这个

**代表性启发的本质：用"像不像"代替"是不是"。**

**在AI创业中：**

- "这个工具看起来很酷"→所以它一定好用→结果不适合你的场景
- "这个人看起来不靠谱"→所以他不适合合作→结果错过了一个天才
- "这个项目看起来和XXX一样"→所以它会成功→结果完全不同

## 🤖 AI实战应用

### 1. 用AI做"代表性启发检测器"

```
我对XXX的判断是：XXX
请帮我检测：
1. 我的判断是否基于"看起来像不像"？
2. 我忽略了哪些重要信息？
3. 如果从数据/统计角度分析，结论会不同吗？
4. 给我一个更客观的判断框架
```

### 2. 用AI做"刻板印象破除器"

```
我认为XXX类型的人/产品/项目一定YYY
请帮我：
1. 找出3个反例
2. 分析为什么我的刻板印象可能错误
3. 给出更准确的判断标准
4. 帮我建立一个"不看外表看本质"的评估框架
```

### 3. 用AI做"数据思维训练"

```
我凭直觉认为XXX成功的概率很大/很小
请帮我：
1. 找到这个领域的基准数据
2. 用统计数据重新评估概率
3. 我的直觉和数据有多大差距？
4. 如何训练自己用数据思考而不是直觉？
```
