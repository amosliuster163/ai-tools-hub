## 🔥 今日思维模型：沉没成本（Sunk Cost Fallacy）

**一句话解释**：你已经花出去的时间、金钱和精力，不应该影响你未来的决定。

---

## 💡 真实案例

你花了30分钟排队等一家网红餐厅，等了15分钟后发现：

> A. 继续等（因为"已经等了15分钟"）
> B. 走人（因为"接下来的30分钟比过去的15分钟更重要"）

**沉没成本陷阱无处不在：**

- 你做公众号3个月没起色→"都做了3个月了，放弃太可惜"→又坚持3个月还是没起色
- 你投了一个项目5万→亏了→"再投5万就能回本"→结果亏了10万
- 你谈了一段烂恋爱→"都在一起3年了，分了太可惜"→又浪费3年

## 🤖 AI实战应用

### 1. 用AI做"沉没成本检测器"

```
我现在面临一个选择：
- 继续做XXX（已投入XXX时间/金钱）
- 放弃做XXX

请帮我分析：
1. 我过去的投入是沉没成本吗？（能不能收回？）
2. 如果我现在从零开始，还会选择做这件事吗？
3. 从未来收益看，继续vs放弃哪个更合理？
4. 请给我一个"零偏见"的建议
```

### 2. 用AI做"及时止损方案"

```
我决定放弃XXX项目了，但心里很不舍
请帮我：
1. 写一份"止损报告"（已投入多少，未来还能收回多少）
2. 从已投入的资源中，有什么可以迁移到新项目的？
3. 帮我计算继续投入的"机会成本"
4. 给我一个"优雅退出"的方案
```

### 3. 用AI建立"止损纪律"

```
请帮我制定一套"止损规则"：
1. 每个项目开始前，设定明确的退出条件
2. 每周用AI评估一次所有进行中的项目
3. 如果触发了退出条件，强制要求复盘并决定去留
4. 记录每次止损决策和后续结果
```
