# 第598期：墨菲定律

> **If it can go wrong, it will.**

## 一句话总结

如果有出错的可能，它迟早会出错——所以要做好最坏的准备。

## 核心洞察

墨菲定律不是诅咒，而是对复杂系统的诚实认知——**在足够多的尝试中，小概率事件一定会发生**。所以不要赌"应该不会出问题"，要假设"一定会出问题"。

### 经典场景

**产品发布**
- "这次应该不会有问题了" → 上线后发现重大bug
- 不是诅咒，是因为你测试的场景永远覆盖不了所有真实情况

**重要演讲**
- 平时练习一百遍都没事 → 上台那天U盘坏了
- 关键节点出问题的概率总是比你想象的高

**旅行打包**
- 没带伞的那天偏偏下雨了
- 带了伞的一周都是晴天

### 墨菲定律的工程学价值

墨菲定律不是让你悲观，而是让你**做好防御**：
- 不要假设一切正常，要假设一定会出问题
- 所以要有备份、有回滚、有应急预案

### 如何用墨菲定律做决策

**事前问三个问题**
1. 这件事最可能出错的环节是什么？
2. 如果出错了，后果有多严重？
3. 我现在能做什么来降低出错的概率或影响？

**建立"防错系统"**
- 重要的文件：备份三份
- 重要的演讲：提前测试设备+准备纸质版
- 重要的项目：设置检查点和回滚方案

## AI实战应用

```
我准备做[某件重要的事]。

请用墨菲定律帮我做风险评估：
1. 列出所有可能出错的环节
2. 每个环节的概率和影响程度
3. 给我对应的预防措施和应急预案
```

## 每日思考

你正在做的哪件事，如果出错了会很惨？你现在有预案吗？
