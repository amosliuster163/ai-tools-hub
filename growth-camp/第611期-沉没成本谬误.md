# 第611期：沉没成本谬误

> **I've already invested so much, I can't quit now.**

## 一句话总结

你继续做一件事不是因为它还有价值，而是因为你已经投入了太多。

## 核心洞察

沉没成本谬误让人类倾向于继续投资已经失败的项目——**你已经花出去的钱、时间、精力，无论你继不继续都无法收回。理性决策应该只看未来，但人类总是被过去绑架**。

### 经典场景

**烂尾项目**
- 你已经花了半年开发一个产品
- 市场反馈很差，但你不想放弃
- "再坚持一下，不能白干了"
- 结果又浪费了半年

**糟糕的关系**
- "我们都在一起5年了，分了太可惜"
- 但过去5年已经过去了
- 关键问题是：未来5年你们会幸福吗？

**股票投资**
- 一只股票亏了50%
- 你不卖，等它回本
- 但如果现在给你等值的现金，你还会买这只股票吗？
- 如果答案是"不会"，那你现在就是在被沉没成本绑架

### 沉没成本的定义

**沉没成本** = 已经发生、不可收回的投入
- 已经花的钱
- 已经花的时间
- 已经付出的精力

这些成本**不应该影响你未来的决策**，因为无论你做什么选择，它们都收不回来了。

### 如何摆脱沉没成本谬误

**归零思考法**
- 假设你今天是第一天接触这个项目/关系/投资
- 你还会选择开始吗？
- 如果答案是"不会"，那你现在应该退出

**机会成本视角**
- 你继续投入的每一分钟，本可以用在更好的事情上
- 继续烂项目的真正成本，是你错过的所有好机会

**设定退出条件**
- 开始一个项目时，提前设定"什么情况下我会退出"
- 到条件就执行，不被情绪绑架

## AI实战应用

```

3. 我继续投入的机会成本是什么
```
