## 🔥 今日思维模型：帕金森定律（Parkinson's Law）

**一句话解释**：工作会自动膨胀，直到占满所有可用的时间。给你一周写一篇公众号，你就会花一周；给你2小时，你2小时也能写完。

---

## 💡 真实案例

为什么你总觉得时间不够用？

> 你计划一周完成一个AI项目 → 结果真的花了一周
> 但其实核心功能2天就能做完 → 剩下5天：纠结配色、反复修改、查资料、发呆
> 
> **不是任务本身需要那么久，而是你给了它那么多时间。**

**帕金森定律的本质：任务时长不由复杂度决定，而由截止日期决定。时间给越多，浪费越多。**

**在AI创业中：**

- 写一篇文章给3天 → 你磨3天 → 给半天也能写完
- 开发一个功能给2周 → 你拖2周 → 给3天也能上线
- 学习一个新工具给1个月 → 你学1个月 → 给1周也能上手

**记住：缩短截止日期，反而能提高效率和产出质量。**

```
我今天有X小时自由时间

请帮我：
1. 给每个任务分配一个"极限截止时间"
2. 按重要性排序

```

### 3. 用AI做"效率倍增器"

```

请帮我：
1. 拆成3个10分钟的微任务
2. 每个微任务的最简执行方案是什么？
3. 有哪些可以用AI代劳的步骤？
```
