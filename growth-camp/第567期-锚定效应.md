# 第567期：锚定效应

> **The first number you see becomes the reference point for everything after.**

## 一句话总结

你看到的第一个数字，会悄悄影响你后面所有的判断。

## 核心洞察

锚定效应是大脑的一个"偷懒机制"——面对不确定的情况，我们会抓住第一个出现的信息作为参考点，然后围绕它调整判断。

### 经典场景

**砍价**
- 商家开价1000，你觉得500太贵，砍到600觉得赚了400
- 但这个东西实际价值可能只有200
- 1000就是"锚"，让你觉得600是便宜

**工资谈判**
- HR先问你"你期望薪资是多少"，你说15K
- 然后HR砍到13K，你觉得还行
- 但如果HR先开价10K，你可能觉得13K很高了

**商品定价策略**
- 先放一个5000块的"旗舰版"，再放一个1999的"标准版"
- 你会觉得1999很划算，因为锚是5000

### 锚定效应的两个关键特征

1. **锚可以是任意数字**——即使是随机生成的数字也会影响判断（实验证明）
2. **即使你知道有锚，你仍然会被影响**——这个偏差很难完全消除

### 如何避免被锚定

**先建立自己的参考系**
- 在谈判前先做功课，知道真实的市场价
- 不要让对方先开价，自己先说一个合理的数字

**警惕"对比陷阱"**
- 商家故意放一个高价选项让你觉得其他选项便宜
- 问自己：如果那个高价选项不存在，我还会觉得这个便宜吗？

## AI实战应用

用AI帮你做**锚定免疫**：

```
我要买/投资/谈判[某件事]。
对方开价/参考价格是：[数字]

请帮我：
1. 找出这个价格可能的锚定效应
2. 提供独立的市场参考价
3. 给出我的合理报价范围
4. 如果我先开口，应该怎么报价
```
