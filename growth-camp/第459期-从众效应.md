## 🔥 今日思维模型：从众效应（Bandwagon Effect）

**一句话解释**：人们倾向于做"大家都在做"的事，即使这件事不一定适合自己。

---

## 💡 真实案例

2023年AI火爆，所有人都说"要做AI"：

> - 你看到别人做AI工具赚钱→你也做→结果没人买
> - 你看到别人做AI教程火了→你也做→结果同质化严重
> - 你看到别人都在学编程→你也学→结果发现自己更适合做产品设计

**从众效应的本质：你放弃了自己的判断，把决策权交给了"人群"。**

**但人群经常是错的：**

- 2021年所有人都在做NFT→现在NFT市场崩了
- 2017年所有人都在做区块链→90%的项目死了
- 2015年所有人都在做O2O→大部分亏光了

---

## 🤖 AI实战应用

### 1. 用AI做"从众检测器"

```
我看到很多人都在做XXX，我也想做
请帮我分析：
1. 这个赛道有多少人参与了？（饱和度）
2. 成功的比例大概是多少？
3. 我的优势和这个赛道的匹配度有多高？
4. 如果我不跟风，有什么差异化的选择？
```

### 2. 用AI找"逆向机会"

```
现在大家都在做：
A. AI工具
B. AI教程
C. AI自媒体

请帮我找出：
1. 这些赛道里被忽略的细分领域
2. 哪些需求是"大家都在追热门，但没人服务"的
3. 给我一个差异化的切入角度
```

### 3. 用AI做"独立思考训练"

```
每当我想跟风做一个"热门"事情时，请先问我3个问题：
1. 我做这个的真实原因是什么？（是看好还是害怕错过？）
2. 我有什么独特的优势能在这个赛道胜出？
3. 如果这个赛道明天就凉了，我还能从中获得什么？
```

## 🎯 今日行动

1. **回想一次你"跟风"的决定**（结果如何？）
2. **用AI分析你当前的选择**：是独立判断还是从众？
3. **找出一个"大家都在追但你没追"的事**，想想为什么
4. **记住：人群不等于正确，独立思考才是你的核心竞争力**
