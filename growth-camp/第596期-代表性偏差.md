# 第596期：代表性偏差

> **That looks like a duck, so it must be a duck.**

## 一句话总结

你根据某个东西"看起来像什么"来判断它是什么——但看起来像不等于就是。

## 核心洞察

代表性偏差让人类倾向于用"典型特征"来判断概率——如果A看起来像B的典型样子，你就觉得A大概率是B，完全忽略了基础概率。

### 经典场景

**以貌取人**
- 戴眼镜、穿格子衫、话不多 → "他肯定是程序员"
- 但世界上不穿格子衫的人比程序员多得多

**创业判断**
- 这个人说话像乔布斯、穿黑色高领衫 → "他一定能创业成功"
- 但成功创业者的基础概率不到1%

**医疗诊断**
- 症状像某种罕见病 → 医生倾向于诊断罕见病
- 但实际上常见病的概率高100倍

### 如何避免代表性偏差

**先问基础概率**
- "这类事情发生的总体概率是多少？"
- 如果基础概率是1%，即使特征再像，实际概率也不会太高

**用AI做概率校准**
- 让你的判断经过"基础概率过滤器"
- 先看整体数据，再看个体特征

## AI实战应用

```
我觉得[某人/某事]像是[某种情况]。

请帮我：
1. 这种情况的基础概率是多少
2. 我的判断中有多少基于代表性特征
3. 用贝叶斯思维重新评估概率
```
