## 🔥 今日思维模型：默认偏见（Default Bias）

**一句话解释**：你倾向于选择"默认选项"，即使有其他更好的选择——因为改变默认需要额外 effort。

---

## 💡 真实案例

你注册一个AI工具：

> 默认订阅方案是"月付¥99" → 你直接点了确定
> 但其实"年付¥799"更划算（相当于月付¥66）
> 但你没改，因为默认是月付
> 
> **你不是不知道年付更便宜，你只是懒得改默认选项。**

**默认偏见的本质：改变需要 effort，而不改变不需要 effort——所以大多数人选择不改变。**

**在AI创业中：**

- 你的产品默认选项设置得好 → 大部分用户都会选 → 你赚到了
- 你让用户自己选方案 → 大部分人选第一个 → 你可能亏了
- 你设置了"免费试用7天，到期自动续费"的默认 → 大部分用户忘记取消 → 你赚到了（但用户可能觉得被坑了）

**记住：好的默认设置是双赢（帮用户做了好决定），坏的默认设置是割韭菜。**

```

```

```

4. 帮我建立一个"反默认"检查清单
```

## 🎯 今日行动

1. **找出一个你"因为它是默认所以选了它"的事**

3. **如果有更好的选择，改掉默认**
4. **记住：默认不是最好的，只是最省力的**
