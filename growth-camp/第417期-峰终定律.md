## 💡 今日模型：峰终定律（Peak-End Rule）

**定义**：人们对一段经历的评价，**不是由整体体验决定的，而是由两个关键点决定：最强烈的瞬间（峰值）和结束的瞬间（终值）**。中间的平淡部分几乎被忽略。

简单说：**一场电影好不好看，你不记得中间80%的剧情，只记得最震撼的场景和结尾。**

---

## 📖 经典实验

### 冰水实验（Kahneman, 1993）

两组实验：
- **A组**：把手放在冰水里60秒（一直很冷）
- **B组**：先把手放在冰水里60秒，然后**水温微微升高1度**（仍然很冷，但稍微好一点点），再放30秒

理性来说：B组多受了30秒罪，应该更难受。

结果：**B组的评价反而更好**。

原因：B组的"终值"稍微好一点——虽然只暖了1度，但结束的时候没那么冷了。

**大脑不是按"总分"评价体验的，是按"最高分"和"最后分"。**

## 🔍 峰终定律的日常表现

| 场景 | 峰值 | 终值 | 整体评价 |
|------|------|------|---------|
| **旅行** | 看到日出的瞬间 | 回家那天的感觉 | "这次旅行太棒了！" |
| **约会** | 第一次牵手 | 分别时的一个拥抱 | "和他在一起很开心" |
| **会议** | 老板突然表扬了你 | 会议最后的一句话 | "今天开会还不错" |
| **面试** | 答对那道难题 | 面试官最后的微笑 | "我感觉有戏" |

### 关键洞察

**你投入100分的努力，如果峰值和终值都很平淡，别人只会给60分。**

**你投入60分的努力，如果峰值很高、结尾很好，别人会给90分。**

## 🤖 AI与峰终定律

### AI如何帮你创造"峰值"和"终值"

| 场景 | AI创造峰值 | AI创造终值 |
|------|-----------|-----------|
| **写公众号文章** | 用AI生成一个震撼的开头钩子 | 用AI设计一个金句结尾 |
| **做PPT汇报** | 用AI生成一个视觉冲击的数据图 | 用AI设计一个行动号召的结尾 |
| **客户沟通** | 用AI帮你想一个超出预期的方案 | 用AI写一封温暖的跟进邮件 |
| **社群运营** | 用AI策划一个惊喜互动环节 | 用AI生成每日晚安金句 |

### 案例：用AI改造你的"峰终体验"

```
改造前（平淡版）：
开头："大家好，今天我们来聊聊AI工具。"（无峰值）
中间：[正常的介绍内容]
结尾："好了，今天就到这里。"（无终值）

改造后（峰终版）：
开头："你每天浪费了2小时在做一件AI 3秒就能搞定的事。"（峰值🔥）
中间：[正常的介绍内容]
结尾："现在就去试这3个工具，明天你就能多睡30分钟。"（终值✨）
```

## 💪 应用策略

### 3步用AI设计峰终体验

**第一步：设计峰值——让AI帮你制造"Wow Moment"**

```
提示词：
我要做[文章/汇报/演讲/社群互动]，请帮我：
1. 设计一个让人"WOW"的开头（可以用数据/故事/反常识观点）
2. 设计一个让人"Wow"的中间亮点（案例/金句/视觉）
3. 要求：前3句话必须让人停不下来
```

**第二步：设计终值——让AI帮你写"难忘结尾"**

```
提示词：
请帮我写一个让人记住的结尾：
- 类型：[金句/行动号召/反问/故事/数据]
- 要求：让人想转发/收藏/立即行动
```

**第三步：用AI做"峰终评分"**

```
提示词：
请评价这篇文章/汇报的峰值和终值：
- 峰值在哪里？（最让人兴奋的部分）
- 终值在哪里？（最后给人的感觉）
- 如果1-10分，你打几分？
- 如何改进？
```
