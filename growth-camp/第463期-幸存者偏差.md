## 🔥 今日思维模型：幸存者偏差（Survivorship Bias）

**一句话解释**：你只看到了成功者的经验，却没看到失败者说了什么——因为他们已经沉默了。

---

## 💡 真实案例

二战期间，军方想给飞机加固装甲：

> 他们统计了返航飞机上的弹孔分布
> 发现机翼弹孔最多，驾驶舱最少
> 结论：加固机翼
> 
> 统计学家沃尔德说：**不对，应该加固驾驶舱**
> 
> 因为：驾驶舱中弹的飞机都没回来

**AI创业中的幸存者偏差：**

- 你看到的：某个AI工具月入10万的成功案例
- 你没看到的：99个做同样工具但失败的人
- 真相：成功可能有幸存者偏差，不是方法对，而是运气好

**自媒体中的幸存者偏差：**

- 你看到的："我做公众号3个月涨粉10万"
- 你没看到的：100个做了1年还是100粉的人
- 真相：成功者的经验不一定可复制

## 🤖 AI实战应用

### 1. 用AI找"沉默的失败者"

```
我看到很多人通过XXX方法成功了
请帮我：
1. 这个方法的失败率大概是多少？
2. 失败的人通常遇到了什么问题？
3. 成功者有没有没说出来的关键因素？
4. 在什么条件下这个方法才有效？
```

### 2. 用AI做"成功率评估"

```
我想做XXX（比如AI工具/自媒体/小程序）
请帮我客观评估：
1. 这个赛道的真实成功率（不是宣传的）
2. 成功的关键因素是什么？（能力/时机/运气/资金）
3. 我个人的条件，成功率大概多少？
4. 有没有风险更低的替代方案？
```

### 3. 用AI学习"失败经验"

```
请帮我收集XXX领域的失败案例：
1. 失败的原因是什么？
2. 他们忽略了什么？
3. 如果重来一次，他们会怎么做？
4. 我能从这些失败中学到什么？
```
