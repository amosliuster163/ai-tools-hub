# 第369期-框架效应

## 📖 核心概念

**框架效应**（Framing Effect）是指：同一个信息，用不同的方式表达，会让人感到完全不同的结果。

简单说：**怎么说，比说什么更重要。**

"手术有90%成功率" vs "手术有10%死亡率"——同一件事，你敢不敢做？

## 🎯 生活案例

### 案例1：定价策略
你开店卖咖啡：
- "9折优惠" vs "立减3元"——哪个更有吸引力？
- "每月¥99" vs "每天¥3.3"——哪个让人更容易掏钱？

框架效应告诉你：**每天¥3.3**更容易成交。

### 案例2：产品包装
你做AI培训课程：
- "10节课" vs "10天掌握AI"——哪个更值？
- "教你用AI" vs "帮你多赚1万"——哪个更想报名？

### 案例3：AI工具描述
你推广AI工具：
- "免费试用7天" vs "每天节省2小时"——哪个让人想注册？
- "功能强大" vs "帮你少加班"——哪个更打动人？

## 💡 成长启示

### 1. 重新框架你的问题
遇到问题时，别只看到一个角度。

- "我怎么还没成功？" → "我已经走了多远？"
- "AI会抢我工作吗？" → "AI能帮我做什么？"
- "我没有时间" → "我把时间花在哪了？"

**换个框架，心情完全不同。**

### 2. 重新框架你的产品
你做产品/服务时，注意怎么"包装"它。

- 不是说"有什么"，而是说"能得到什么"
- 不是说"多少钱"，而是说"省多少钱"
- 不是说"多难"，而是说"多值"

### 3. 重新框架你的失败
创业失败不是"失败了"，而是"排除了一个错误选项"。

**每次失败都是一次数据点，不是终点。**

## 🤖 AI实战应用

### AI提示词框架效应
**场景**：你写的AI提示词效果不好。

**框架效应法**：
换个说法，效果完全不同。

**框架A（负面）**：
```
不要写太长的文章，不要跑题，不要说废话。
```

**框架B（正面）**：
```
写500字以内的精炼文章，紧扣主题，每句话都有价值。
```

同一件事，AI在框架B下表现好得多。

### AI产品定价框架
**场景**：你做了个AI工具，不知道怎么定价。

**框架效应法**：

| 定价方式 | 用户感受 | 转化率 |
|----------|---------|--------|
| ¥199/年 | "好贵" | 低 |
| ¥0.5/天 | "便宜" | 中 |
| "每天省2小时" | "超值" | 高 |

**最优框架**：不是卖"功能"，是卖"时间"。

### AI引流文案框架
**场景**：写公众号文章标题，没人点。

**框架效应法**：

| 标题 | 点击率预估 |
|------|-----------|
| "AI工具使用教程" | 低 |
| "3个AI工具让我每天少加班2小时" | 高 |
| "我用AI做了一人公司，月入2万" | 更高 |

**核心**：不是"教你什么"，而是"你能得到什么"。

## 🎯 今日行动

1. **框架练习**：把你现在的待办清单，从"必须做"换成"选择做"
2. **产品重框架**：看你现在的产品/服务，换个说法试试
3. **Prompt改写**：拿你最常用的一个Prompt，从负面指令改成正面指令
