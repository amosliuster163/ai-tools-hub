## 🔥 今日思维模型：费曼技巧（Feynman Technique）

**一句话解释**：如果你不能用简单的语言把一件事讲给一个外行听，说明你自己也没真正理解。

---

## 💡 真实案例

你学了一个AI工具：

> 看了一堆教程 → 觉得自己懂了 → 让你给别人讲一遍 → 卡壳了
> 
> **不是你没学，是你没"教过"。**

**费曼技巧的本质：教是最好的学。能讲清楚，才算是真懂了。**

**在AI创业中：**

- 你觉得自己的产品很好，但投资人一问就懵——因为你没真正想清楚
- 你学了很多AI知识，但用不出来——因为你没教过别人
- 你做了一个复杂的方案，但团队看不懂——因为你自己也没理清

**记住：复杂不是深度，能把复杂讲简单才是深度。**

---

## 🤖 AI实战应用

### 1. 用AI做"费曼技巧练习器"

```
我刚学了XXX，想检验自己是否真的懂了
请帮我：
1. 让我用简单语言向你解释一遍
2. 指出我解释中的漏洞和不清晰之处
3. 问我3个问题，检验我的理解深度
4. 根据我的回答，告诉我哪里还需要加强
```

### 2. 用AI做"知识简化器"

```
我有一个复杂的概念：XXX
请帮我：
1. 用1句话解释它（给外行听）
2. 用一个比喻解释它
3. 用一个日常例子解释它
4. 帮我检查：我的理解是否有漏洞？
```

### 3. 用AI做"教学脚本生成器"

```
我要给别人讲XXX，让他们一听就懂
请帮我：
1. 核心知识点是什么？（不超过3个）
2. 用什么比喻最直观？
3. 用什么例子最贴切？
4. 帮我写一个"5分钟讲清楚"的教学脚本
```
