## 🔥 今日思维模型：确认偏误（Confirmation Bias）

**一句话解释**：你倾向于寻找和相信支持自己已有观点的信息，忽略相反的证据。

---

## 💡 真实案例

你觉得"短视频做不起来"，然后：

> - 你看到"短视频已经饱和"的文章→"果然如此！"
> - 你看到"XXX做短视频月入10万"→"那只是运气好"
> - 你看到一个失败案例→"看吧，我就说不行"

**你不是在找真相，你是在找"证明自己正确"的证据。**

**确认偏误在AI创业中尤其危险：**

- 你觉得"这个方向不行"→所以只关注失败案例→越来越觉得不行→真的不做了→错过机会
- 你觉得"AI工具一定赚钱"→所以只看成功案例→投入大量时间→发现不是那么简单

**打破确认偏误的唯一方法：主动寻找反面证据。**

---

## 🤖 AI实战应用

### 1. 用AI做"反面证据挖掘机"

```
我相信XXX，请帮我：
1. 找出3个反面证据（为什么XXX可能是错的）
2. 找出3个成功案例的反面（看起来成功但实际有问题）
3. 找出3个失败案例的正面（看起来失败但有隐藏机会）
4. 给我一个最"刺痛"的反驳观点
```

### 2. 用AI做"观点压力测试"

```
我的观点是：XXX一定会成功
请扮演我的辩论对手，用以下方法反驳我：
1. 指出我的逻辑漏洞
2. 提供反面数据或案例
3. 问3个我可能回答不上来的问题
4. 帮我看到我没考虑到的风险
```

### 3. 用AI做"每周偏见检查"

```
这是我本周的重要决定：
- 决定1：XXX
- 决定2：YYY

请帮我检查：
1. 我是否只看了支持自己的信息？
2. 我有没有忽略什么关键的反面证据？
3. 如果我的决定是错的，最可能的原因是什么？
```
