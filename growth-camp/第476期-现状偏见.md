## 🔥 今日思维模型：现状偏见（Status Quo Bias）

**一句话解释**：你倾向于维持现状，即使改变会带来更好的结果。

---

## 💡 真实案例

你用了3年的笔记软件：

> 朋友推荐了一个更好的 → 你说"我这个用习惯了" → 但其实新软件的效率高2倍
> 
> 你不是不知道新软件更好，你只是懒得改变

**现状偏见在AI创业中：**

- 一直用免费AI工具 → 不舍得付费 → 其实付费工具效率高10倍
- 一直用微信推广 → 不试小红书 → 其实小红书用户更精准
- 一直自己写文章 → 不用AI辅助 → 其实AI能帮你提高3倍产出

**维持现状是最省力的，但也是最可惜的。**

## 🤖 AI实战应用

### 1. 用AI做"现状偏见检测器"

```
我现在在用XXX工具/方法做XXX
请帮我分析：
1. 我继续用它，是因为它真的好，还是因为习惯？
2. 有哪些替代方案可能更好？
3. 如果我从零开始，会选哪个？
4. 改变的成本有多大？不改变的代价有多大？
```

### 2. 用AI做"改变成本分析"

```
我在考虑是否从XXX切换到YYY
请帮我：
1. 切换的学习成本（时间/精力/金钱）
2. 切换后的预期收益提升
3. 不切换的机会成本
4. 给我一个"换/不换"的量化决策
```

### 3. 用AI做"渐进式改变方案"

```
我想改变XXX现状，但怕一下子改不过来
请帮我：
1. 设计一个渐进式改变计划（分3步）
2. 每一步的最小可行行动是什么？
3. 如何验证改变是否有效？
4. 如果改变失败了，如何安全回退？
```
