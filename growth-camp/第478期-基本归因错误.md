## 🔥 今日思维模型：基本归因错误（Fundamental Attribution Error）

**一句话解释**：别人做错了，你认为是他人品有问题；自己做错了，你认为是环境有问题。

---

## 💡 真实案例

你的公众号文章阅读量低：

> 你的解释：平台限流+算法变了+用户口味变了（环境因素）
> 别人的解释：你的内容质量下降了（个人因素）
> 
> 谁的判断更准确？
> 
> 大概率是别人的。

**基本归因错误在AI创业中：**

- 你的AI工具没人用："用户不懂欣赏"（怪用户），而不是"产品没做好"（看自己）
- 你的自媒体不涨粉："平台限流"（怪平台），而不是"内容不够好"（看自己）
- 你的合作方不回复："他不重视我"（怪对方），而不是"我的方案不够有吸引力"（看自己）

**记住：环境因素和个人因素都存在，但你高估了个人因素，低估了环境因素。**

---

## 🤖 AI实战应用

### 1. 用AI做"归因检测器"

```
我觉得XXX失败的原因是XXX（我认为是别人的问题/环境问题）
请帮我客观分析：
1. 我的归因是否偏向基本归因错误？
2. 有哪些环境因素我可能忽略了？
3. 有哪些个人因素我可能没看到？
4. 给我一个更平衡的归因分析
```

### 2. 用AI做"自我反思助手"

```
我最近在XXX方面遇到了困难
请帮我做一次客观的归因分析：
1. 列出所有可能的原因（个人+环境）
2. 每个原因的证据是什么？
3. 哪些是我能控制的？哪些是我不能控制的？
4. 我应该重点改进哪些方面？
```

### 3. 用AI做"他人行为分析"

```
XXX（同事/用户/合作方）做了XXX事，我觉得他不靠谱
请帮我分析：
1. 有哪些环境因素可能导致他这样做？
2. 如果换一个人，在那种环境下会不会也这样做？
3. 我是否高估了他的个人因素？
4. 如何在不责怪他的情况下解决这个问题？
```
