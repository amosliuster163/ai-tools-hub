# 第609期：确认偏误

> **You don't see what you don't want to see.**

## 一句话总结

你倾向于寻找、记住和相信那些符合你已有观点的信息，而忽略反面证据。

## 核心洞察

确认偏误是人类最普遍、最顽固的认知偏差——**不是你在收集证据再做判断，而是你先有了判断再去找证据**。你以为你在理性分析，实际上你只是在给自己的观点找帮手。

### 经典场景

**社交媒体信息茧房**
- 你关注和你观点一致的人
- 算法推荐更多你认同的内容
- 你越来越确信"所有人"都这么想
- 但其实只是你被关在了回音室里

**投资决策**
- 你买了某只股票后，只看利好消息
- 利空消息被你潜意识过滤掉
- 直到亏了很多钱才意识到问题

**人际关系**
- 你觉得某个人不靠谱
- 之后他做的每件事你都解读为"不靠谱"的证据
- 他做的好事你自动忽略了

### 确认偏误的运作机制

1. **选择性搜索**——只找支持自己的信息
2. **选择性解读**——同样的信息，有利于自己的就认真看，不利的就挑刺
3. **选择性记忆**——记住支持自己的，忘掉打脸的

### 如何对抗确认偏误

**主动寻找反证**
- 每当你形成一个观点，刻意去找反驳这个观点的证据
- 问自己："如果我的观点是错的，证据会是什么？"

**红队思维**
- 让AI或朋友扮演"反对者"
- 让他们专门攻击你的观点
- 如果攻击后你的观点还能站住脚，那才值得相信

## AI实战应用

```
我相信[某个观点/决定]。

请帮我做"红队分析"：
1. 列出3个这个观点可能错误的理由
2. 找一个反面的案例或数据
3. 告诉我如果我是错的，后果是什么
```

## 每日思考

你最近哪个观点，可能只是确认偏误在起作用？
