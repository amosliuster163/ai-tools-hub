## 🔥 今日思维模型：框架效应（Framing Effect）

**一句话解释**：同样的信息，不同的表述方式，会导致完全不同的决策。"手术成功率90%"让你安心，"手术死亡率10%"让你害怕——但它们是同一件事。

---

## 💡 真实案例

为什么你觉得这个AI课程"值得买"？

> "365天只需365元，每天只要1块钱" → 你觉得便宜
> "一个课程卖365元" → 你觉得贵
> 
> **同一个价格，不同框架，你的感受完全不同。**

**框架效应的本质：人们做决策时，不是看绝对价值，而是看"被框定的方式"。框架比内容更能影响判断。**

**在AI创业中：**

- 定价框架：¥365/年 → "每天1元" → 感觉便宜
- 损失框架："不学AI，你会被淘汰" → 比"学AI，你会进步"更有驱动力
- 社交框架："5000人已加入" → 比"这是一个学习平台"更有说服力
- 时间框架："限时3天" → 比"长期有效"更能促使用户行动

**记住：怎么说，往往比说什么更重要。**

## 🤖 AI实战应用

### 1. 用AI做"营销文案框架优化"

```
我的产品是XXX，价格是¥XXX
请帮我：
1. 用5种不同的"框架"写推广文案
2. 每种框架的侧重点是什么？（价格/价值/损失/社交/时间）
3. 哪种框架最适合我的目标用户？
4. 帮我做一个"框架对比测试"方案
```

### 2. 用AI做"决策框架检测"

```
我正在做一个决定：[描述]
请帮我：
1. 这个决定是否受到了"框架"的影响？
2. 如果换个说法描述同样的选项，我会选一样的吗？
3. 帮我剥离框架，看清本质
```

### 3. 用AI做"个人说服技巧"

```
我想说服XXX做XXX（比如让老板采纳AI方案）
请帮我：
1. 用什么"框架"最有说服力？
2. 从对方的角度看，什么框架最有效？
3. 帮我写3个不同框架的版本，选最好的
```
