## 🔥 今日思维模型：刺猬法则（Hedgehog's Dilemma）

**一句话解释**：离得太近会互相伤害，离得太远又会觉得冷——你需要找到那个"刚刚好"的距离。

---

## 💡 真实案例

你和AI的使用关系：

> 完全依赖AI："所有东西都让AI写" → 内容没有个人风格 → 用户觉得像机器
> 完全不依赖AI："AI写的不行，都自己来" → 效率太低 → 产出跟不上
> 
> 刚刚好的距离：AI做初稿，你改风格和观点

**刺猬法则的本质：不是"近"或"远"的选择，而是"刚刚好"的距离。**

**在AI创业中：**

- 你和用户的关系：太近（什么都答应）→ 被用户绑架；太远（高冷）→ 用户流失
- 你和AI的关系：完全依赖 → 失去自我；完全排斥 → 效率低下
- 你和团队的关系：管得太细 → 团队没自主权；管得太松 → 方向失控

```

4. 给我一个具体的执行方案
```

```

1. AI擅长什么？我擅长什么？

3. 如何分工才能既高效又保持个人风格？
4. 给我一个具体的"人机协作"边界清单
```
