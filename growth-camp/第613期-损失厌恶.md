# 第613期：损失厌恶

> **Losing hurts twice as much as winning feels good.**

## 一句话总结

失去100块的痛苦，是得到100块的快乐的2倍。

## 核心洞察

损失厌恶是行为经济学的核心发现——**人类对损失的敏感度远高于对收益的敏感度**。这不是性格问题，是进化留下的本能：在野外，错过一次机会只是饿一顿，犯一次错可能就没命了。

### 经典场景

**股票投资**
- 赚了20%就拿不住，想赶紧落袋为安
- 亏了20%反而死扛，不愿意卖
- 因为卖出去就意味着"承认损失"，这太痛苦了

**产品定价**
- "7天免费试用"比"买一个月试试"有效10倍
- 因为试用后，取消订阅=失去已经拥有的东西
- 损失厌恶让用户不愿意放弃

**谈判策略**
- 不要告诉对方"你能得到什么"
- 告诉对方"你不合作会失去什么"
- 损失框架比收益框架更有说服力

### 损失厌恶的数字

研究表明：**损失的心理影响约等于同等收益的2-2.5倍**

- 丢100块的痛苦 ≈ 需要得到200-250块才能平衡
- 这意味着你在决策时天然偏向"不失去"而不是"获得更多"

### 如何利用损失厌恶

**销售中**
- 试用期、免费体验、限时优惠
- 核心逻辑：先让用户"拥有"，再让他们怕"失去"

**个人决策中**
- 意识到你在被损失厌恶驱动吗？
- 有时候"不行动"的成本比"行动失败"的成本更高

### 如何克服损失厌恶

**理性评估**
- 问自己："如果我还没有这个东西，我愿意花多少钱买？"
- 如果不愿意花那么多，说明你只是在怕失去

**看机会成本**
- 你死守一个亏损的投资
- 但同样的钱投在别处可能赚更多
- 不改变本身就是最大的损失

## AI实战应用

```
我在纠结是否要放弃/退出[某件事]。

请帮我：
1. 分析我的犹豫中有多少来自损失厌恶
2. 如果我不存在损失厌恶，我会怎么做
3. 计算"不改变"的隐性成本
```

## 每日思考

你最近哪个决定，是因为"怕失去"而不是"想获得"？
