# 第563期：费曼技巧

> **If you can't explain it simply, you don't understand it well enough.**

## 一句话总结

能用大白话讲清楚的东西，才是你真懂的东西。

## 核心洞察

费曼技巧不是学习方法，而是**检验你是否真懂**的照妖镜——你以为自己会了，一开口就露馅。

### 四个步骤

**第一步：选一个概念**
- 不要选太难的，选你觉得"差不多懂了"的那个

**第二步：假装教给一个12岁的孩子**
- 不用专业术语
- 不用复杂公式
- 用最简单的比喻和语言

**第三步：发现讲不清楚的地方**
- 这就是你的知识盲区
- 回去翻资料，重新理解

**第四步：用更简单的语言重新讲一遍**
- 直到一个外行也能听懂

### 经典场景

**面试前复习**
- 看了一百遍笔记觉得都会了
- 一开口讲给室友听，发现有三块根本讲不明白
- 那三块就是面试官会深挖的地方

**写方案给客户**
- 自己觉得逻辑很清楚
- 客户看完问你"所以到底要做什么"
- 因为你用了太多内部术语

**学完一个新框架**
- 跟着教程走了一遍觉得学会了
- 自己从零开始写，发现处处卡壳
- 因为你只记住了步骤，没理解原理

### 为什么费曼技巧有效

1. **被动学习留存率只有10%**（听讲座、看视频），**主动学习留存率75%**（教别人）
2. 当你试图教别人的时候，你会**自动发现逻辑漏洞**
3. 简化语言的过程就是**深度理解**的过程

### AI时代的费曼技巧

有了AI，你可以随时随地做"费曼测试"——让AI扮演12岁孩子，你试着讲给它听，让它提问。

## AI实战应用

用AI做**费曼测试**——让AI扮演外行，你讲给它听：

```
你现在是一个12岁的初中生，完全不懂[领域]。
我现在要给你讲解[概念]，请你：
1. 认真听我讲
2. 遇到听不懂的地方随时问我
3. 最后告诉我你觉得哪里最 confusing

我开始讲了：[你的讲解]
```

或者反过来：

```
请用小学生都能听懂的方式，解释[复杂概念]。
要求：不用专业术语，只用日常比喻。
```

## 每日思考

你现在正在学的东西，你能用三句话讲给一个外行听吗？试试。
