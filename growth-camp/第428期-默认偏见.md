## 💡 今日模型：默认偏见（Default Bias）

**定义**：人们倾向于**维持现状或接受默认选项**，即使改变只需要轻轻一戳。默认不是中立的设计——它是最强大的选择架构。

简单说：**90%的人不会取消"自动续费"，不是因为没钱，而是因为默认就是续费。**

---

## 📖 经典实验

### 器官捐献率对比

经济学家研究了欧洲各国的器官捐献率：

**选择加入模式**（默认不捐献，需要主动勾选）：
- 德国：12%的人选择捐献
- 丹麦：4%的人选择捐献

**选择退出模式**（默认捐献，需要主动取消）：
- 法国：99.9%的人"选择"捐献
- 奥地利：99.8%的人"选择"捐献

**同样的国家、同样的文化，只是改了默认选项，捐献率从4%跳到99.9%。**

## 🔍 默认偏见的日常表现

| 场景 | 默认选项 | 结果 |
|------|---------|------|
| **App安装** | "同意收集数据"已勾选 | 95%的人直接点下一步 |
| **订阅服务** | "自动续费"已开启 | 大多数人不主动关闭 |
| **401K养老金** | 自动加入计划 | 参与率从37%→86% |
| **隐私设置** | "公开可见" | 很少人改为私密 |
| **免费试用** | "试用结束后自动扣费" | 大多数人忘了取消 |

### 为什么默认如此强大？

**三个原因**：

| 原因 | 说明 |
|------|------|
| **懒惰/省事** | 改变需要额外操作，维持默认最省力 |
| **暗示推荐** | "既然默认是这个，说明它应该是好的" |
| **损失恐惧** | "如果我改了，会不会错过什么？" |

## 🤖 AI与默认偏见

### AI如何利用默认偏见帮你

**场景1：让AI设置"好默认"**

```
❌ 坏默认：
"今天要不要用AI？"（默认=不用）
→ 结果：几乎永远不用

✅ 好默认：
"每天早上8点AI自动整理今日简报"
→ 结果：每天自动获得价值
```

**场景2：用AI帮你"反默认偏见"**

```
提示词：
我目前的[工作/生活/学习]中有哪些默认设置，
可能正在悄悄影响我的选择？
请帮我：
1. 列出当前默认设置
2. 分析哪些对我有利
3. 建议哪些需要主动修改
```

### 设计中的默认偏见

| 产品设计 | 默认设置 | 商业目的 |
|---------|---------|---------|

## 💪 应用策略

### 3步用默认偏见改变自己和产品

**第一步：检查你的"坏默认"**

| 领域 | 可能的坏默认 | 好默认替代 |
|------|-------------|-----------|
| 手机使用 | 通知默认开启 | 通知默认关闭 |
| 饮食健康 | 外卖App推荐高热量 | 推荐健康选项 |
| 学习习惯 | "有空再学习" | "每天15分钟自动提醒" |
| AI使用 | "需要时才问AI" | "每天AI主动推送1条建议" |

**第二步：让你的好习惯成为"默认"**

```
✅ 把AI工具放在桌面第一位（默认打开它）
✅ 把手机设为灰度模式（默认降低吸引力）
✅ 把运动服放在床头（默认看到就穿）
✅ 把书架放在沙发旁边（默认看到就拿）
```

**第三步：用AI做"默认设计器"**

```
提示词：
我想培养[某个好习惯]，
请帮我设计一个"默认选项"策略：
1. 环境怎么布置让好习惯成为默认？
2. 手机/App怎么设置减少坏选择？
3. 有什么自动化工具可以让好行为不需要意志力？
```
