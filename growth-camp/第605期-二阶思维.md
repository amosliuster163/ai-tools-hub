# 第605期：二阶思维

> **And then what?**

## 一句话总结

不要只看第一个结果，要看结果的后续影响——每个决定都会引发连锁反应。

## 核心洞察

一阶思维只看直接后果（"做了A会发生B"），二阶思维看后果的后果（"B发生后还会引发C和D"）。**大多数人停在一阶，高手会想到三阶、四阶甚至更远**。

### 经典场景

**抗生素的发明**
- 一阶效果：杀死细菌，治愈疾病 ✅
- 二阶效果：细菌产生耐药性 ❌
- 三阶效果：超级细菌出现，威胁全人类 ❌❌

**价格战**
- 一阶效果：销量上升 ✅
- 二阶效果：竞争对手跟进降价 ❌
- 三阶效果：行业整体利润下降，大家都受损 ❌❌

**AI替代人工**
- 一阶效果：企业降本增效 ✅
- 二阶效果：大量失业，消费力下降 ❌
- 三阶效果：经济循环受阻，企业也受影响 ❌❌

### 二阶思维的实践方法

**问"然后呢？"**
- 每次想到一个结果，追问"然后呢？"
- 至少追问三层

**考虑时间维度**
- 短期有利 ≠ 长期有利
- 今天的解决方案可能是明天的问题

**画因果链**
- A → B → C → D
- 不要停在B，继续推到D

### 注意：过度思考也是问题

- 不是所有决定都需要想到十阶
- 重大决定：多想几层
- 日常决定：一阶就够了

## AI实战应用

```
我准备做[某个决定]。

请用二阶思维帮我分析：
1. 一阶效果（直接结果）
2. 二阶效果（结果的后果）
3. 三阶效果（再往后推一步）
4. 哪些是正面连锁反应，哪些是负面连锁反应
```

你最近的哪个决定，只考虑了一阶效果？
