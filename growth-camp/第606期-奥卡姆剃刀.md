# 第606期：奥卡姆剃刀

> **The simplest explanation is usually the right one.**

## 一句话总结

如果多个解释都能说明同一个现象，最简单的那个往往是对的。

## 核心洞察

奥卡姆剃刀是中世纪哲学家威廉·奥卡姆提出的思维原则——**不要不必要的假设**。每当你为一个理论添加新的假设，它出错的概率就增加一分。

### 经典场景

** conspiracy theories**
- 登月是假的 → 需要假设NASA造假、全球媒体配合、苏联不揭穿...
- 登月是真的 → 只需要假设人类有能力登月
- 哪个假设更少？明显是后者

**产品bug排查**
- 你以为是一个复杂的系统交互导致的
- 实际上就是一个if写反了
- 新手总往复杂方向想，高手先排除最简单的可能性

**人际关系**
- 他没回你消息：
  - 解释A：他故意冷落你，因为你对他有意见（需要多个假设）
  - 解释B：他忙，没看到（只需要一个假设）
- 奥卡姆剃刀告诉你：先假设B

### 注意：简单 ≠ 对

奥卡姆剃刀说的是"最简单的解释通常更可能是对的"，不是"一定是对的"。
- 它帮你优先排查方向
- 但如果最简单的解释被证伪了，你再考虑更复杂的

## AI实战应用

```
我在分析[某个问题]，有几个可能的解释。

请用奥卡姆剃刀帮我：
1. 列出每个解释需要多少假设
2. 哪个解释最简洁
3. 哪个应该优先验证
```

## 每日思考

你最近哪个问题，可能有一个更简单的解释被你忽略了？
