# 第592期：禀赋效应

> **You overvalue what you already own.**

## 一句话总结

你拥有的东西，在你眼里比它实际的价值更高。

## 核心洞察

禀赋效应揭示了一个反直觉的现象——**一旦你拥有某样东西，你对它的估值就会显著上升**。这不是因为东西变好了，是因为"拥有"本身改变了你的感知。

### 经典实验

马克杯实验：
- 一组学生拿到马克杯（拥有者），一组没有
- 问拥有者：你愿意多少钱卖？平均要价7块
- 问没拥有的人：你愿意多少钱买？平均出价3块
- **同一个杯子，只是因为"拥有"，估值翻了一倍多**

### 经典场景

**卖二手房**
- 你住的房子，在你心里值200万
- 市场评估价150万
- 因为你给它加了"感情分""装修分""回忆分"

**舍不得扔的东西**
- "这个以后可能用得上"
- 其实一年都没用过一次
- 但你高估了它未来的价值

**创业项目**
- 你花了一年做的产品，即使数据很差你也舍不得放弃
- "我们已经投入了这么多""这个方向是有价值的"
- 但市场不买账

### 禀赋效应的两个驱动力

1. **损失厌恶**——失去一个已有的东西比获得同样东西的痛苦更大
2. **情感依恋**——拥有让物品和个人经历产生了关联

### 如何对抗禀赋效应

**假设你不拥有它**
- 问自己：如果我现在没有这个东西，我愿意花多少钱买它？
- 如果答案远低于你的心理价位，说明禀赋效应在起作用

**定期做"断舍离"**
- 每季度审视你拥有的东西
- 问：如果没有它，我会买吗？不会 → 扔掉/卖掉

**商业决策中的禀赋效应**
- 评估项目时，假设你是新加入的，你会继续投吗？
- 如果不会，说明你在被禀赋效应影响

## AI实战应用

用AI帮你做**禀赋效应检测**：

```
我有一件东西/项目/关系舍不得放手。

请帮我：
1. 如果我现在不拥有它，我愿意花多少成本获取它
2. 我给出的"不放手"理由中，哪些是客观的，哪些是情感依恋
3. 给我一个"从零开始"的评估
```
