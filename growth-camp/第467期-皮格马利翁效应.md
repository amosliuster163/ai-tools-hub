## 🔥 今日思维模型：皮格马利翁效应（Pygmalion Effect）

**一句话解释**：你对别人的期望，会影响他们的表现——你期望越高，他们往往表现得越好。

---

## 💡 真实案例

1968年，哈佛心理学家罗森塔尔做了一个经典实验：

> 他随机选了几个学生，告诉老师："这些学生很有潜力"
> 实际上这些学生和其他人没有区别
> 
> 8个月后：这些学生的成绩确实提高了
> 
> 因为：老师的期望改变了老师的行为→老师更关注这些学生→学生表现更好

**期望塑造现实。**

**在你的团队管理中：**

- 你觉得某个员工不行→你对他态度冷淡→他表现更差→"果然不行"
- 你觉得某个员工有潜力→你对他更有耐心→他表现更好→"果然有潜力"

**在你和AI的互动中：**

- 你觉得"AI很笨"→你给AI的指令很敷衍→AI回复很烂→"果然笨"
- 你觉得"AI很强"→你精心设计Prompt→AI回复很牛→"果然强"

## 🤖 AI实战应用

### 1. 用AI做"高期望管理"

```
我想让AI帮我完成XXX
请帮我设计一套"高期望Prompt"：
1. 先告诉AI它擅长什么（建立角色期待）
2. 给出高质量的标准
3. 让它知道你对结果有高要求
4. 最后再加一句鼓励
```

### 2. 用AI做"团队期望优化"

```
我有3个团队成员，我的初始印象是：
- A：能力一般
- B：有潜力但还需要成长
- C：核心骨干

请帮我：
1. 我的这些期望会不会影响我对他们的态度？
2. 如果用皮格马利翁效应，我应该如何调整期望？
3. 给每个人一个"正向期望"的描述
4. 如何通过改变期望来提升团队整体表现？
```

### 3. 用AI做"自我期望提升"

```
我对自己在XXX方面的期望是：XXX
请帮我：
1. 这个期望是太高还是太低？
2. 如果提高20%，我能不能达到？
3. 给我一段"自我期望宣言"，让我每天读一遍
4. 设计一个反馈机制，让我能看到进步
```

## 🎯 今日行动

1. **检视你对AI的期望**：你是不是觉得"AI不过如此"？试着提高期望，看看结果是否不同

3. **检视你对自己的期望**：你是不是低估了自己的潜力？
4. **记住：期望不是预测，期望是创造**
