# 第569期：框架效应

> **The same choice, presented differently, leads to completely different decisions.**

## 一句话总结

同样一件事，换个说法，你的决定就变了。

## 核心洞察

框架效应揭示了一个残酷的事实——**人的决策不是理性的，而是被"表达方式"操控的**。同样的数据，正着说和反着说，人们会做出完全相反的选择。

### 经典场景

**医疗决策实验**
- 方案A："能救活200人" → 72%的人选A
- 方案B："400人会死" → 只有22%的人选B
- **但这两个方案是一模一样的！**（600人中救200=400人死）
- 正框架（救人）vs 负框架（死人），决策完全不同

**商品促销**
- "95%脱脂" vs "含5%脂肪"
- 你觉得前者更健康，但它们是同一个东西

**合同条款**
- "提前解约需支付违约金" vs "履行完合同可获退款"
- 前者让人想放弃，后者让人想坚持
- 本质是一样的经济结果

### 框架效应的两种主要类型

**收益框架**（正面表述）→ 人倾向于保守
- "这个方案有80%的成功率" → 你觉得靠谱

**损失框架**（负面表述）→ 人倾向于冒险
- "这个方案有20%的失败率" → 你觉得危险

### 如何识别和抵御框架效应

**翻译成绝对数字**
- 不要听"95%脱脂"，看营养成分表
- 不要听"80%成功率"，看具体多少人成功多少人失败

**正反两种框架都想一遍**
- 主动把正框架翻译成负框架
- 把负框架翻译成正框架
- 如果两种翻译后你觉得应该做同一个决定，那就是理性的

## AI实战应用

用AI帮你做**框架解构**：

```
有人向我推荐[产品/方案/投资]，他是这样说的：
"[原始表述]"

请用框架效应分析：
1. 这个表述用的是收益框架还是损失框架
2. 换成相反的框架重新表述
3. 去掉所有修饰词，只保留核心事实
4. 给我一个中性的决策建议
```
