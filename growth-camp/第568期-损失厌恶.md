# 第568期：损失厌恶

> **Losing hurts twice as much as winning feels good.**

## 一句话总结

亏100块的痛苦，是赚100块的快乐的**两倍**。

## 核心洞察

损失厌恶是人类进化留下的本能——在原始社会，错过一顿饭只是饿肚子，但被野兽吃掉就什么都没了。所以大脑天生对"损失"更敏感。

### 经典场景

**股票投资**
- 涨了10%你赶紧卖，怕利润回吐
- 跌了10%你死拿着，"不卖就不算亏"
- 结果小赚就跑，大亏死扛

**免费试用套路**
- 给你7天免费会员，到期自动扣费
- 你懒得取消，因为"取消=失去"
- 商家赌的就是你怕失去已有的东西

**不愿离开舒适区**
- 现在的工作不好，但跳槽意味着失去稳定
- "失去稳定"的痛苦 > "获得更好机会"的快乐
- 所以你原地不动

### 损失厌恶的数据

行为经济学实验证明：**损失的痛苦是收益快乐的2-2.5倍**

这意味着：
- 你丢100块的难受程度 = 你捡到250块的开心程度
- 这就是为什么人天生保守

### 如何利用/避免损失厌恶

**利用它做营销**
- "限时优惠，错过就没了" 比 "现在买能省50" 更有效
- 强调"失去什么"比强调"得到什么"更有说服力

**避免它做决策**
- 做决定的时候问自己：我是因为怕失去什么才不做，还是因为这件事真的不好？
- 把"损失"重新定义为"投资别处的机会"

## AI实战应用

用AI帮你做**损失厌恶测试**：

```
我犹豫要不要做[某件事]。
我担心的损失是：[列出]
我可能获得的收益是：[列出]

请用损失厌恶框架帮我分析：
1. 我的犹豫中有多少是理性的风险评估
2. 有多少是单纯的情绪性损失厌恶
3. 如果把"不做"也定义为一种损失，我会怎么选
```

## 每日思考

你今天因为"怕失去什么"而放弃了什么事？那个放弃是真的明智，还是损失厌恶在作怪？
