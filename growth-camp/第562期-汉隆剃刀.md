# 第562期：汉隆剃刀

> **Never attribute to malice that which is adequately explained by stupidity.**

## 一句话总结

别人的错误，大多不是故意的，只是能力不够或信息不足。

## 核心洞察

汉隆剃刀是一剂**情绪解毒药**——它帮我们把"他是不是针对我"的猜疑，转化为"他可能只是没搞清楚"的理性判断。

### 经典场景

**同事回邮件没抄送你**
- 第一反应：他是不是故意的？想绕过我？
- 汉隆剃刀：他可能只是忘了，或者觉得不需要

**领导没采纳你的建议**
- 第一反应：领导对有意见？
- 汉隆剃刀：领导可能只是没看到你的方案，或者信息不对称

**客户突然取消订单**
- 第一反应：客户是不是被竞品抢走了？
- 汉隆剃刀：客户可能只是预算调整，跟任何人无关

### 为什么我们总爱往坏处想

1. **进化本能**：原始社会，把威胁误判为安全比把安全误判为威胁更危险
2. **自我中心偏差**：我们习惯从自己的角度看问题，觉得别人也该这么想
3. **信息不对称**：你看到的只是结果，不知道对方的决策过程

### 汉隆剃刀不是万能药

⚠️ **注意**：汉隆剃刀说的是"不要**轻易**归因于恶意"，不是"永远不可能有恶意"。

真正聪明的人：
- 先用汉隆剃刀排除大多数情况
- 再留一只眼睛观察**重复出现的模式**（偶尔一次是疏忽，次次如此就要警惕了）

### 应用框架

遇到让你不舒服的事，按顺序问：
1. 他可能不知道吗？（信息差）
2. 他可能不会吗？（能力差）
3. 他可能没注意到吗？（注意力差）
4. 以上都排除了，再考虑是不是故意的

## AI实战应用

用AI帮你做**沟通降噪**——把情绪化的猜测转化为理性的分析：

```
我遇到了一个让我很不舒服的情况：[描述]
我的第一反应是：[你的猜测]

请用汉隆剃刀原则帮我分析：
1. 有哪些非恶意的解释？
2. 每种解释的可能性有多大？
3. 我应该怎么验证？
```

## 每日思考

今天有没有什么事让你觉得"他是故意的"？如果用汉隆剃刀重新分析，会得出什么不同的结论？
