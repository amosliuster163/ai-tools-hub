## 🔥 今日思维模型：基本归因错误（Fundamental Attribution Error）

**一句话解释**：你评价别人时，倾向于归因于性格或运气；评价自己时，倾向于归因于环境或处境。他赚钱是因为运气好，我赚钱是因为努力。

---

## 💡 真实案例

你为什么觉得那个AI大V"只是运气好"？

> 他发了1000篇内容 → 你说"他运气好碰到热点"
> 他自己做产品月入10万 → 你说"赶上了AI风口"
> 他3年做到50万粉丝 → 你说"他有团队"
> 
> 但你自己的小成绩 → 你觉得是"努力的成果"
> 
> **双重标准：别人的成功=运气，自己的成功=实力；别人的失败=能力差，自己的失败=环境差。**

**基本归因错误的本质：我们更容易看到别人的行为，却看不到他们的处境；更容易看到自己的处境，却忽略自己的行为模式。**

**在AI创业中：**

- 看到同行赚钱 → "他只是运气好" → 错失学习机会
- 自己做不成 → "是大环境不好" → 错失反思机会
- 别人被骂 → "他情商低" → 自己被骂 → "是键盘侠太多"

**记住：学会用同样的标准评价别人和自己，才能看清真相。**

## 🤖 AI实战应用

### 1. 用AI做"公平归因分析"

```
我看到XXX（某人的成功/失败案例）
我的第一反应是：[你的归因]
请帮我：
1. 如果用同样的标准分析我自己，会得出什么结论？
2. 我是否忽略了环境因素（对他的）或行为因素（对自己的）？
3. 给我一个"公平的"归因分析
```

### 2. 用AI做"成功拆解"

```
XXX做成了XXX事
请帮我：
1. 运气成分占多少？实力成分占多少？
2. 哪些是"不可复制"的运气因素？
3. 哪些是"可以学习"的实力因素？
4. 我如何复制他的实力因素？
```

### 3. 用AI做"失败反思"

```
我在XXX事上失败了
我的第一反应是：[你的归因]
请帮我：
1. 这个归因中有多少是"找借口"？
2. 如果我是一个客观的第三方，会怎么归因？
3. 我能在哪些方面做出改变？
```
