# 第622期：基本归因错误

> **They failed because they're stupid. You failed because you had a bad day.**

## 一句话总结

你总是把别人的失败归因于他们的性格，把自己的失败归因于外部环境。

## 核心洞察

基本归因错误是社会心理学最普遍的认知偏差之一——**评价别人时，我们高估个人因素、低估环境因素；评价自己时，我们高估环境因素、低估个人因素**。这解释了为什么人际关系中充满了误解和双标。

### 经典场景

**职场评价**
- 同事迟到了 → "他就是不靠谱"
- 你迟到了 → "今天堵车太严重了"
- 同一个行为，两种归因

**社交媒体**
- 别人分享成功 → "他只是运气好"
- 你分享成功 → "这是努力的回报"
- 别人失败 → "他能力不行"
- 你失败 → "这次情况特殊"

**亲密关系**
- 伴侣忘记纪念日 → "他不在乎我"
- 你忘记纪念日 → "最近工作太忙了"
- 同样的错误，完全不同的解释

### 基本归因错误的运作机制

```
观察别人的行为 → 直接归因于性格（内在）
观察自己的行为 → 先考虑环境（外在）
```

这不是因为你是坏人，是因为：
- 你看别人，只能看到行为
- 你看自己，能看到所有背景和原因

### 如何减少基本归因错误

**换位思考**
- 当你想评价别人时，问自己："如果我做了同样的事，我会怎么解释？"
- 如果解释不同，你正在犯基本归因错误

**考虑环境因素**
- 别人的行为可能有你不知道的背景
- 你看到的只是冰山一角

**用行为描述代替性格判断**
- 不说"他不靠谱"
- 说"他这次没有按时完成任务"
- 前者是性格判断，后者是行为描述

## AI实战应用

```

2. 如果我做了同样的事，我会怎么解释
3. 给我一个更客观的行为描述
```
