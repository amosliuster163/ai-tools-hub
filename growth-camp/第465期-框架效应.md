## 🔥 今日思维模型：框架效应（Framing Effect）

**一句话解释**：同一件事，用不同的方式描述，会让人做出不同的决定。

---

## 💡 真实案例

医生告诉患者手术风险：

> 说法A："这个手术的成功率是90%"
> 说法B："这个手术的死亡率是10%"
> 
> 听到A的患者：大部分同意手术
> 听到B的患者：大部分拒绝手术

**同一个事实，不同框架，完全不同的决定。**

**在AI创业中的框架效应：**

- 你说"我做AI工具失败了"vs"我排除了一个不可行的方向"
- 用户说"这个工具收费29块/月"vs"每天不到1块钱"
- 投资人说"这个赛道90%的人会失败"vs"这个赛道10%的人成功了"

**你被框架影响而不自知，就会做出非理性的决定。**

## 🤖 AI实战应用

### 1. 用AI做"框架检测器"

```
我看到一条信息：XXX
请帮我：
1. 这条信息用了什么框架？（正面/负面/中性）
2. 如果换个框架描述，意思会变吗？
3. 这个框架在引导我做什么决定？
4. 去掉框架后，事实是什么？
```

### 2. 用AI做"文案框架优化"

```
我要写一段推广文案：XXX
请用5种不同的框架重写：
1. 正面框架（强调收益）
2. 负面框架（强调不做的损失）
3. 数字框架（用数据说话）
4. 故事框架（用案例引入）
5. 对比框架（前后对比）

请告诉我哪个框架最适合我的目标用户。
```

### 3. 用AI做"决策去框架化"

```
我在犹豫要不要做XXX
请帮我：
1. 去掉所有情绪化描述，只列出客观事实
2. 列出做和不做的具体利弊
3. 给我一个"零偏见"的建议
4. 如果换一个完全中立的第三方，他会怎么建议？
```
