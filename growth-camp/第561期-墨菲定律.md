# 第561期：墨菲定律

> **Anything that can go wrong will go wrong.**

## 一句话总结

如果一件事有可能出错，那它迟早会出错。

## 核心洞察

墨菲定律不是悲观主义，而是一种**防御性思维**——它提醒我们：不要寄希望于"应该不会出问题"，而要提前准备"万一出问题怎么办"。

### 经典场景

**项目上线翻车**
- 测试环境跑了一百遍都没问题，一上线就崩溃
- 不是因为运气差，而是因为"可能出错的环节"真的存在，只是之前没触发

**出门必忘东西**
- 每次赶时间的时候，一定会发现忘带钥匙/手机/充电宝
- 越不想出错的地方，越容易出错

**演讲紧张**
- 练了十遍都很顺，上台那一刻突然忘词
- 因为"紧张可能导致忘词"这个风险一直存在

### 为什么墨菲定律总是应验

1. **选择性记忆**：顺利的时候你不注意，一出问题你就记住了
2. **概率必然性**：只要概率不是零，重复足够多次，就一定会发生
3. **连锁反应**：一个小问题往往暴露了更大的系统性漏洞

### 应对策略

**防御性设计**
- 假设一定会出错，那怎么让它影响最小？
- 备份、容错、降级方案

**提前演练最坏情况**
- 不是问"应该怎么做"，而是问"最坏情况是什么，我能承受吗"

**建立检查清单**
- 把"可能出错的事"列成清单，逐一确认
- 飞行员起飞前的检查清单就是经典应用

## AI实战应用

用AI做"墨菲预演"——在项目启动前，让AI帮你列出**所有可能出错的环节**：

```
你是一个风险管理专家。请帮我分析这个项目的"墨菲清单"：
1. 列出所有可能出错的环节（至少10个）
2. 评估每个环节的发生概率和影响程度
3. 给出预防和应急方案

项目描述：[你的项目]
```

## 每日思考

如果今天最重要的那件事**一定会出错**，你会做哪些准备？
