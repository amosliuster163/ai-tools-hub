🏫 中国大学历史

Claude Code 技能包 — 输入大学名称，自动查询可信信息，按用户画像智能适配输出

🧩 Claude Code 技能 · v2026.1

📖 这是什么？

一个专为 Claude Code 打造的技能包，用来查询中国大学信息。不是简单的百科搬运，而是做了三层功夫：

🔍 自动联网搜索

每次查询自动搜索官网、教育部信息，交叉验证确保准确

👤 用户画像适配

小学生问→1-3句话讲亮点；研究者问→深度数据+时间线

📋 结构化输出

基本信息、学科实力、历史沿革、知名校友，清晰易读

✅ 信源可验证

每条关键信息标注 [来源：xxx]，用户可以点过去核对

⚡ 安装方法

只需两步即可安装到 Claude Code：

# 1. 克隆/下载技能包 git clone https://github.com/amosliuster163/chinese-university-history-skill.git # 2. 复制到 Claude Code 技能目录 mkdir -p ~/.claude/skills/chinese-university-history cp -r chinese-university-history-skill/* ~/.claude/skills/chinese-university-history/

💡 安装后重启 Claude Code 即可生效。输入"介绍一下浙江大学"测试。

🎬 使用示例

场景一：小学生问大学

<用户> 清华大学是什么样的学校？ 清华大学 这是中国最顶尖的大学之一，属于"985工程"和"双一流"高校，相当于大学里的"国家队"。 🌟 最厉害的地方：清华的工科在全国排第一，很多造火箭、造芯片的科学家都从这里毕业。 [来源：清华大学官网 + 教育部]

场景二：考生对比学校

<用户> 武大和华科哪个好？ **对比：武汉大学 vs 华中科技大学** | 维度 | 武汉大学 | 华中科技大学 | |------|---------|------------| | 创办时间 | 1893年（自强学堂） | 1952年（华中工学院） | | 学科评估 A+ 数 | 4个 | 4个 | | 双一流学科数 | 11个 | 9个 | | 校区位置 | 武汉·珞珈山 | 武汉·喻家山 | **要点分析** - 武大以人文社科和理科见长，校园环境优美 - 华科以工科和医科见长，科研产出密集 - 两校都是教育部直属全国重点大学，均为双一流建设高校 [来源：教育部学科评估 + 两校官网]

场景三：研究者查深度数据

<用户> 我要写一篇关于浙大科研的论文，需要详细数据 [深度模式] 浙江大学 — 教育部直属全国重点大学，双一流建设高校 **学科评估详情** - 计算机科学与技术：A+（第五轮，2022年） - 控制科学与工程：A+ - 光学工程：A+ - 软件工程：A+ ...（全部学科按等级排列） **科研平台** - 国家重点实验室：10个（含计算机辅助设计与图形学、工业控制技术等） - 国家工程研究中心：7个 - 2011协同创新中心：2个 **历史发展详细时间线** - 1897年：求是书院创立 [来源：浙大官网] - 1928年：定名国立浙江大学 - 1998年：四校合并组建新浙江大学 ... [来源：浙江大学官网 + 教育部]

✨ 核心特色

特色 说明
信源分级 官网 > 教育部 > 学术排名 > 百科，P3级信源（自媒体等）绝不引用
数据分级策略 稳定数据（创立年、校训）读本地知识库 + 交叉验证；年度数据（排名、就业率）每次联网搜最新
预装知识库 985/211/双一流完整名录 + 头部10所985高校详细数据（学科评估、科研平台等）
兜底机制 "宁可不说，不可瞎编" — 找不到可靠信息时明确告知用户
学校更名处理 用户说"北京广播学院"→自动提示"现更名为中国传媒大学"
